ถ้าคุณเคยเห็นคนตกหมึกด้วยเหยื่อปลอมรูปกุ้ง แล้วสงสัยว่าทำไมเขาต้องกระตุกเป็นจังหวะ ทำไมบางคนได้หมึกทั้งวัน แต่บางคนตีจนเมื่อยแล้วยังว่างเปล่า คลิปนี้ตอบคำถามนั้นได้ดีมาก

ผู้สอนคือ **มิยาซาวะ ยูกิโนริ (宮澤幸則)** DAIWA Angler และหนึ่งในผู้บุกเบิกการตกหมึกด้วยอีจิในเวลากลางวันของญี่ปุ่น เขามีประสบการณ์ทั้งการตกหมึก การพัฒนาอุปกรณ์ และการแข่งขันตกปลาชนิดอื่น ๆ

คลิปนี้เป็นภาคต่อจากตอนพื้นฐานที่สอนวิธีใช้อีจิและอุปกรณ์ ส่วนตอนนี้คือ **ภาคสนามจริง** ตั้งแต่การเลือกจุดตก การปล่อยอีจิให้จม การกระตุก ไปจนถึงการสู้หมึกและการเก็บรักษา

## สรุปสั้นใน 1 นาที

- **จุดตกที่ควรเช็กก่อน** มักอยู่ที่โคนเขื่อนส่วนตื้น มุมเขื่อน ปลายเขื่อน และร่องน้ำเดินเรือที่มีขอบลาดชัน
- **หลังตี** ปล่อยให้อีจิจมเองตามแรงของมัน ประมาณ 3 วินาทีก่อนเริ่มจัดสาย อย่าดึงสายตึงหรือหย่อนเกินไป
- **กระตุกประมาณทุก 10 วินาที** และใช้ทั้งกระตุกครั้งเดียวแรง ๆ กับกระตุกต่อเนื่อง
- **หลังได้หมึก** ให้กลับไปตกที่ระดับความลึกเดิม เพราะหมึกมักอยู่ชั้นเดิม
- **จังหวะน้ำเริ่มไหล** มักเป็นช่วงที่หมึกแอคทีฟมากขึ้น ส่วนช่วงน้ำนิ่งให้พักหรือเปลี่ยนจุด
- **น้ำขุ่นเล็กน้อย** ดีกว่าน้ำใสมาก เพราะหมึกระวังตัวน้อยลง แต่ขุ่นเกินไปก็ไม่ดี
- **ถ้าอีจิติดสาหร่าย** แปลว่าตกในแนวสาหร่าย ให้กรอเร็วขึ้นเล็กน้อย จุดที่เกือบไม่ติดสาหร่ายคือจุดที่ดีที่สุด
- **เห็นหมึก** ให้ตีเลยไปด้านหน้า ปล่อยอีจิจมช้า ๆ กระตุกตรงหน้า แล้ว **หยุดนิ่ง** - จังหวะหยุดคือจุดที่หมึกมักกัด
- **ตอนสู้หมึก** ตั้ง drag ให้หลวมและตักจากด้านหลัง เพราะหมึกมักพุ่งถอยหลังเมื่อตกใจ

## 1. Eging คืออะไร และต้องใช้อะไรบ้าง

**Eging (エギング)** คือการตกหมึกด้วยเหยื่อปลอมที่เรียกว่า **อีจิ (エギ)** ซึ่งทำเลียนแบบกุ้งหรือปลาเล็ก อีจิมีหลายขนาด หลายสี และหลายอัตราการจม

เป้าหมายหลักในคลิปคือ **หมึกอะโอริ (アオリイカ / bigfin reef squid)** ซึ่งอยู่ในกลุ่มเดียวกับหมึกกล้วยที่พบได้ในน่านน้ำไทย

### 1.1 อุปกรณ์พื้นฐานโดยประมาณ

| อุปกรณ์ | ขนาดที่นิยม |
|---|---|
| คัน | คันอีจิ้งยาวประมาณ 7'6"–8'6" |
| รอก | สปินนิ่ง 2500–3000 |
| สายหลัก | PE (สายถัก) 0.6–1.0 |
| ลีดเดอร์ | ฟลูออโรคาร์บอน 3–5 ปอนด์ |
| อีจิ | เบอร์ 2.5–3.5 ตามขนาดหมึกและความลึก |

ในคลิปใช้แนวอุปกรณ์ DAIWA Emeraldas ซึ่งเป็นซีรีส์สำหรับอีจิ้งโดยเฉพาะ และใช้ **อีจิแบบปกติ (normal)** ไม่ใช่รุ่นหนักเป็นพิเศษ จากนั้นปรับความเร็วการจมด้วยการควบคุมสายและจังหวะกระตุก

### 1.2 เลือกอีจิ: ขนาด สี และอัตราการจม

อีจิที่ดีไม่ใช่ "เบอร์ใหญ่ที่สุด" แต่คืออันที่ **จมถึงชั้นน้ำที่หมึกอยู่และดูน่ากินในสภาพน้ำวันนั้น** ให้ดูสามอย่างนี้ก่อน

1. **ขนาด (เบอร์)** - ดูความลึก กระแสน้ำ และขนาดหมึก
2. **สีและความโปร่งแสง** - ดูความใสของน้ำและแสง
3. **อัตราการจม (sink rate)** - ดูว่าอยากให้อีจิอยู่ชั้นน้ำนานแค่ไหน

| สถานการณ์ | ขนาดที่เริ่มใช้ | สีที่เข้าท่า | อัตราการจม |
|---|---|---|---|
| น้ำตื้นไม่เกิน 3 ม. / หมึกเล็กฤดูใบไม้ร่วง | 2.5 | โปร่งใส, สีธรรมชาติ, สีใสแกมน้ำตาล | ช้า–ปานกลาง |
| ตกทั่วไป 3–8 ม. / หมึกขนาดกลาง | 3.0 | สีธรรมชาติ, สีกุ้ง, สีชาร์ต | ปานกลาง |
| น้ำลึกหรือกระแสแรง | 3.5 | สีเข้ม, สีส้ม, สีเรืองแสง | เร็ว |
| น้ำขุ่นเล็กน้อย | 3.0–3.5 | ชาร์ต, ส้ม, ชมพู | ปานกลาง |
| กลางคืน / ใต้แสงไฟ | 3.0–3.5 | เรืองแสง (glow), UV | ปานกลาง–เร็ว |
| หมึกระวังตัวจัด / น้ำใสมาก | 2.5–3.0 | โปร่งใส, สีธรรมชาติ, สีด้าน | ช้า |

**ขนาดและน้ำหนักโดยประมาณ:** เบอร์ 2.5 ราว 10–12 ก., เบอร์ 3.0 ราว 14–16 ก. และเบอร์ 3.5 ราว 18–20 ก. (น้ำหนักจริงขึ้นกับรุ่นและผู้ผลิต)

**อ่านอัตราการจมให้เป็น:** อัตราการจมมักเขียนเป็น "วินาทีต่อเมตร" (เช่น 3 วินาที/เมตร) ตัวเลขยิ่งมาก อีจิยิ่งจมช้า ถ้าอยากให้อีจิค้างในชั้นน้ำนานขึ้น ให้เลือกอีจิจมช้า หรือใช้ **curve fall** ด้วยการตึงสายเล็กน้อยตอนจม

**เรื่องสีแบบง่าย ๆ:** น้ำใสใช้สีธรรมชาติหรือสีโปร่งแสงเพื่อไม่ให้หมึกเห็นความผิดปกติ น้ำขุ่นใช้สีที่ตัดกับน้ำ เช่น ชาร์ตหรือส้ม ส่วนกลางคืนใช้สีเรืองแสงหรือ UV เพื่อให้หมึกเห็นจากระยะไกล

**UV คืออะไร:** สี UV คือสีที่เรืองแสงใต้แสงอัลตราไวโอเลต ช่วยให้หมึกมองเห็นเหยื่อได้ในที่แสงน้อยหรือน้ำขุ่นเล็กน้อย

> **เคล็ดลับเสริม:** ตัวเลขน้ำหนักอีจิและอัตราการจมข้างต้นเป็นค่าประมาณจากสเปกอีจิทั่วไป ไม่ได้ระบุในคลิป ให้ยึดหลัก "น้ำตื้น–หมึกระวังตัว = เล็กลงและจมช้า, น้ำลึก–กระแสแรง = ใหญ่ขึ้นและจมเร็ว" แล้วปรับหน้างานอีกครั้ง

### 1.3 ตั้งอุปกรณ์ก่อนตก

นอกจากคัน รอก สาย และอีจิแล้ว สิ่งที่ทำให้ตกได้ต่อเนื่องคือการเตรียมของให้พร้อม

| สิ่งที่ต้องเช็ก | วิธีตั้ง / เตรียม |
|---|---|
| Drag | ตั้งให้หลวมพอที่หมึกตัวใหญ่ยังดึงสายออกได้ ไม่ล็อกตาย |
| ปม PE–ลีดเดอร์ | เช็กให้แน่นและเรียบ ผ่านไกด์ได้ไม่สะดุด |
| ตะขออีจิ | ต้องคมและไม่บิ่น ถ้าขอทู่ให้เปลี่ยนอีจิ |
| สวิง | ต้องเปิดได้ไวและมีขนาดพอรับหมึกตัวใหญ่ |
| กล่องเย็น | ใส่น้ำแข็งและน้ำทะเล/ผ้าเปียก ไม่ใช่น้ำจืดแช่หมึก |
| ผ้าเช็ดมือ | ใช้เช็ดมือก่อนจับสายและก่อนจับหมึก |
| อีจิสำรอง | เตรียมต่างสี ต่างเบอร์อย่างละ 1–2 ตัว |

## 2. หาจุดตก: หมึกชอบอยู่ตรงไหน

มิยาซาวะพาไล่ดูจุดสำคัญตามแนวเขื่อนและท่าเรือ ซึ่งเป็นจุดที่มือใหม่สามารถหาได้ไม่ยาก

### 2.1 โคนเขื่อนส่วนตื้น

จุดแรกที่ควรเช็กคือ **บริเวณโคนเขื่อนหรือฐานเขื่อนที่เป็นน้ำตื้น**

เหตุผลคือน้ำตื้นมักมีอาหารและหมึกที่กำลังหาอาหารอยู่ รวมถึงหมึกที่แอคทีฟสูง จึงมีโอกาสเจอหมึกได้มากกว่าจุดลึกทั่วไป

### 2.2 มุมเขื่อน

**มุมหรือส่วนที่เขื่อนเปลี่ยนทิศทาง** เป็นจุดที่กระแสน้ำและอาหารมารวมกัน

นอกจากนี้ ใต้มุมเขื่อนอาจมีกองหินหรือสิ่งกีดขวางที่มองเห็นได้ด้วยแว่นตากันแดดแบบโพลาไรซ์ ถ้าเห็นเป็นเงาเข้ม ๆ ใต้น้ำ แสดงว่าเป็นโครงสร้างที่ดีมาก

### 2.3 ปลายเขื่อน

**ปลายเขื่อน** เป็นจุดระดับท็อปของหลายพื้นที่ เพราะมีทั้งการเคลื่อนที่ของปลาเล็กและหมึก รวมถึงกระแสน้ำที่พาอาหารเข้ามา

ถ้าไปตกเขื่อนที่ไม่คุ้นเคย ให้ลองเช็กปลายเขื่อนก่อนเสมอ

### 2.4 ร่องน้ำเดินเรือและขอบลาดชัน

บริเวณที่เรือเข้าออกหรือ **ร่องน้ำเดินเรือ (ミオ筋)** มักถูกขุดให้ลึกกว่าบริเวณรอบ ๆ

จุดที่น่าสนใจคือ **ขอบหรือไหล่ของร่องน้ำ (駆け上がり)** ซึ่งเป็นรอยต่อระหว่างน้ำลึกกับน้ำตื้น เป็นจุดที่หมึกใช้ในการเคลื่อนที่และล่าอาหาร

### 2.5 แหล่งวางไข่ในฤดูใบไม้ผลิ

ในช่วงฤดูใบไม้ผลิ หมึกตัวใหญ่จะเข้ามาวางไข่บริเวณแหล่งหญ้าทะเลหรือสาหร่าย

บางครั้งสามารถมองเห็นตัวหมึกได้ด้วยตาเปล่า และตกแบบ **sight fishing** คือตีไปยังด้านหน้าตัวหมึกเล็กน้อยแล้วล่อให้มันเข้ามากอด

### 2.6 จุด "竿抜け" ที่คนอื่นมองข้าม

จุดที่มือใหม่มักมองข้ามคือ **竿抜け (ซาโอะ-นุเกะ)** หรือจุดที่มีสิ่งกีดขวางจนคนอื่นไม่ค่อยตก

แต่ในความจริง หมึกอาจหลบอยู่ตามซอกหินหรือสิ่งกีดขวางเหล่านั้น เพราะถูกรบกวนน้อยกว่า

### 2.7 จุดตื้นที่คาดไม่ถึง

โดยเฉพาะในฤดูใบไม้ร่วง หมึกอาจเข้ามาในน้ำตื้นมากกว่าที่คิด อย่ามองข้ามจุดตื้นใกล้ฝั่งเพียงเพราะคิดว่า "ตรงนี้คงไม่มีหมึก"

### 2.8 ตารางเลือกจุดแบบเร็ว

| จุด | ทำไมหมึกชอบ | ช่วงที่เหมาะ |
|---|---|---|
| โคนเขื่อนน้ำตื้น | มีอาหารและหมึกที่กำลังหากิน | เช้า, น้ำขึ้น, วันที่อยากได้จำนวน |
| มุมเขื่อน | กระแสน้ำชนกันและพาอาหารมา | ช่วงน้ำไหล |
| ปลายเขื่อน | ปลาเล็กเคลื่อนผ่านและมีความลึกหลายระดับ | ตลอดวัน โดยเฉพาะน้ำไหล |
| ร่องน้ำเดินเรือ | เป็นขอบระหว่างน้ำลึกกับน้ำตื้น | น้ำขึ้น–น้ำลง |
| แปลงหญ้าทะเล / แหล่งวางไข่ | หมึกใหญ่เข้ามาวางไข่ | ฤดูใบไม้ผลิ, กลางวัน |
| 竿抜け (ซาโอะ-นุเกะ) | มีสิ่งกีดขวางและถูกรบกวนน้อย | วันที่คนเยอะ |
| น้ำตื้นใกล้ฝั่ง | หมึกเล็กเข้ามาหาอาหาร | ฤดูใบไม้ร่วง |

### 2.9 ลำดับไล่จุดให้ไม่เสียเวลา

> **เคล็ดลับเสริม:** ลำดับนี้เป็นแนวทางเริ่มต้นสำหรับมือใหม่ ไม่ใช่ลำดับตายตัว ให้ปรับตามน้ำขึ้นน้ำลงและจุดที่คนยืนอยู่

1. เริ่มจาก **ปลายเขื่อนหรือมุมเขื่อน** ซึ่งมีโอกาสเจอหมึกเคลื่อนที่ผ่าน
2. ไล่มาที่ **โคนเขื่อนน้ำตื้น** โดยเฉพาะช่วงเช้าหรือน้ำขึ้น
3. เช็ก **ขอบร่องน้ำ** ด้วยการนับเวลาจนอีจิถึงก้น
4. ถ้าคนเยอะ ให้มองหา **竿抜け** ที่มีหินหรือสิ่งกีดขวาง
5. ก่อนกลับ อย่าลืมลอง **จุดตื้นใกล้ฝั่ง** โดยเฉพาะฤดูใบไม้ร่วง

> **เคล็ดลับเสริม:** ถ้าตีครบทุกทิศและเปลี่ยนจังหวะแล้วยังไม่มีการตามหรือกัดใน 5–10 ตี ให้ย้ายจุดหรือพัก แล้วกลับมาใหม่ตอนน้ำเริ่มไหล ดีกว่าฝืนตกจุดเดิมนาน ๆ

## 3. ตีและปล่อยอีจิให้ถูกจังหวะ

### 3.1 เช็กด้านหลังก่อนตี

ก่อนตีทุกครั้ง ให้มองด้านหลังและรอบตัวก่อน เพราะบริเวณเขื่อนอาจมีคนเดินหรือมีสิ่งกีดขวาง

### 3.2 ปล่อยให้อีจิจมเอง

หลังตี ให้ปล่อยอีจิจมตามแรงโน้มถ่วงของมัน อย่าเพิ่งกระตุกทันที ในคลิปผู้สอนปล่อยให้จมประมาณ **3 วินาที** ก่อนเริ่มจัดสาย เพื่อให้อีจิลงตัวและสายตึงพอดี

หลักคือ **ไม่ตึงเกินไปและไม่หย่อนเกินไป** ถ้าสายหย่อนมากเกินไป จะรู้สึกถึงการกัดของหมึกได้ยาก และแรงกระตุกจะส่งไปถึงอีจิไม่เต็มที่

อีกจุดที่สำคัญคือ **มองสาย** เพราะหมึกมักกัดตอนอีจิกำลังจม สายอาจหยุดหรือเปลี่ยนทิศทางก่อนที่เราจะรู้สึกถึงแรงกัด

### 3.3 จัดสายเมื่อถูกลม

ถ้ามีลมทำให้สายหย่อนหรือโค้ง ให้ใช้ปลายคันดึงสายให้ตึงขึ้นเล็กน้อย หรือเปลี่ยนมุมยืนเพื่อให้สายตรงกับอีจิ บางครั้งการขยับไปยืนทางขวาเล็กน้อยก็ทำให้สายตรงกับอีจิได้ง่ายขึ้น

### 3.4 นับเวลาจนถึงก้น

ในคลิปใช้เวลาประมาณ **30 วินาที** กว่าอีจิจะจมถึงก้น (ขึ้นกับความลึกและอัตราการจมของอีจิ)

ให้จับจังหวะนี้ไว้ เพราะเมื่อรู้ว่าอีจิอยู่ระดับไหน จะควบคุมการกระตุกได้แม่นขึ้น

### 3.5 กระตุกครั้งแรกเบา ๆ

เมื่ออีจิถึงก้น ให้กระตุกเบา ๆ หนึ่งครั้งเพื่อเริ่มการทำงาน จากนั้นปล่อยให้อีจิจมและกระตุกเป็นจังหวะ

### 3.6 Curve fall

บางจังหวะสามารถคุมสายให้ตึงเล็กน้อยตอนอีจิจม เพื่อให้อีจิจมช้าและโค้งกว่าเดิม (curve fall) ทำให้เหยื่อดูเป็นธรรมชาติและอยู่ในระยะที่หมึกกัดได้นานขึ้น

ในคลิปใช้ท่าทางแบบ **"ตึงสายเล็กน้อย" (糸張り気味)** แล้วปล่อยให้อีจิจมลงช้า ๆ ไม่ปล่อยสายหย่อนจนอีจิจมดิ่งตรง ๆ วิธีนี้ช่วยให้อีจิอยู่ใกล้หมึกนานขึ้นและเห็นท่าทางการจมชัดขึ้น

### 3.7 อ่านสายระหว่างอีจิจม

| สิ่งที่เห็นหรือรู้สึก | ความหมาย | สิ่งที่ควรทำ |
|---|---|---|
| สายหยุดหรือสะบัดก่อนถึงก้น | หมึกอาจกอดอีจิระหว่างจม | อย่าตึงแรง ค่อย ๆ เก็บสายให้ตึงแล้วยกคัน |
| สายโค้งเป็นตัว U | ลมหรือน้ำพาสายหย่อน | ยกปลายคันหรือเปลี่ยนจุดยืนให้สายตรง |
| ถึงก้นเร็วเกินคาด | น้ำตื้นหรืออีจิจมเร็ว | เปลี่ยนอีจิจมช้าลงหรือลดการนับ |
| ยังไม่ถึงก้นสักที | น้ำลึกหรืออีจิเบาเกิน | เพิ่มเวลานับหรือใช้อีจิที่หนักขึ้น |
| สายกระตุกสั้น ๆ เป็นจังหวะ | อาจเป็นปลาเล็กหรืออีจิโดนสิ่งกีดขวาง | กระตุกเบา ๆ แล้วหยุดดูว่ามีน้ำหนักหมึกหรือไม่ |

## 4. กระตุกและหยุด: หัวใจของการตกหมึก

### 4.1 กระตุกทุกประมาณ 10 วินาที

จังหวะพื้นฐานในคลิปคือ **กระตุกประมาณทุก 10 วินาที** แล้วปล่อยให้อีจิจมหรือหยุดนิ่งในช่วงสั้น ๆ

### 4.2 ใช้สองสไตล์สลับกัน

มิยาซาวะใช้การกระตุก 2 แบบสลับกัน

1. **กระตุกครั้งเดียวแรง ๆ** เพื่อให้อีจิกระโดดหรือเปลี่ยนทิศทาง
2. **กระตุกต่อเนื่องหลายครั้ง** เพื่อให้อีจิว่ายหนีเป็นจังหวะ

การสลับสองแบบช่วยให้หมึกที่ตามดูอยู่ตัดสินใจกัดได้ง่ายขึ้น

ถ้าหมึกไม่ตอบสนอง ให้เปลี่ยนความแรงในการกระตุก ความเร็วในการกรอ และจังหวะการหยุดบ้าง อย่าใช้จังหวะเดิมตลอดเวลา

### 4.3 หลังได้หมึก ให้กลับไปที่ระดับเดิม

เมื่อหมึกกัดหรือได้หมึกหนึ่งตัว ให้กลับไปตกที่ **ระดับความลึกเดิม** เพราะหมึกมักรวมตัวอยู่ในชั้นน้ำเดียวกัน

### 4.4 จังหวะ "หยุด" คือจังหวะกัด

หลายครั้งหมึกจะตามอีจิมาแต่ไม่กัด จนกระทั่งอีจิ **หยุดนิ่งกะทันหัน** หรือเปลี่ยนทิศทางกะทันหัน หมึกจะตัดสินใจกัดในจังหวะนั้น

ดังนั้นอย่ากระตุกตลอดเวลา ต้องมีจังหวะหยุดให้หมึกได้ "ตัดสินใจ"

### 4.5 ตารางเลือกจังหวะกระตุก

| จังหวะ | วิธีทำ | เหมาะกับสถานการณ์ |
|---|---|---|
| กระตุกครั้งเดียว | กระตุกหนึ่งครั้งให้อีจิกระโดดหรือเปลี่ยนทิศ แล้วปล่อยจม | ค้นหาพื้นที่ใหม่หรือหมึกยังไม่ตาม |
| กระตุกต่อเนื่อง | กระตุกติดกัน 2–3 ครั้งแล้วหยุด | หมึกตามมาแต่ยังไม่กัด |
| Curve fall | ตึงสายเล็กน้อยตอนอีจิจม ให้จมช้าและโค้ง | น้ำใส หมึกระวังตัว หรือหมึกตัวใหญ่ |
| ค่อย ๆ ยกขึ้น | ลากอีจิขึ้นช้า ๆ แล้วหยุดใกล้ผิวน้ำ | เห็นหมึกตามขึ้นมาถึงชั้นบน |
| หยุดนิ่งนานขึ้น | กระตุกแล้วปล่อยนิ่ง ๆ ไม่รีบกระตุกซ้ำ | หมึกใหม่หรือน้ำนิ่ง ต้องการให้หมึกตัดสินใจ |

> **เคล็ดลับเสริม:** ความยาวช่วงหยุดไม่ต้องตายตัว เริ่มจาก 3–5 วินาที แล้วสังเกตปฏิกิริยาของหมึก ถ้าหมึกตามแต่ไม่กัด ให้หยุดนานขึ้นหรือเปลี่ยนเป็นอีจิที่จมช้าลง

### 4.6 ข้อผิดพลาดในการกระตุก

- **กระตุกถี่เกินไป** จนไม่มีจังหวะหยุด หมึกไม่มีโอกาสกอดอีจิ
- **กระตุกแรงตลอดเวลา** ทำให้สายหย่อนหรือขอฉีกขาด โดยเฉพาะหมึกตัวใหญ่
- **กรอเก็บสายตลอด** จนอีจิไม่เคยจมเต็มที่
- **เปลี่ยนระดับความลึกทุกครั้ง** โดยไม่จำว่าหมึกอยู่ชั้นไหน
- **ไม่มองสาย** จึงพลาดการกัดตอนอีจิกำลังจม
- **ใช้จังหวะเดิมซ้ำ ๆ** ทั้งที่หมึกไม่ตอบสนอง ควรสลับความแรง ความเร็ว และช่วงหยุด

## 5. อ่านน้ำ: กระแสน้ำ ความขุ่น และสาหร่าย

### 5.1 จังหวะน้ำขึ้นน้ำลง

หมึกจะแอคทีฟมากขึ้นเมื่อน้ำเคลื่อนที่ โดยเฉพาะ **ช่วงที่น้ำเริ่มไหลหลังน้ำนิ่ง**

ในคลิปแนะนำให้ดูตารางน้ำขึ้นน้ำลง และจับช่วงที่น้ำเริ่มเคลื่อน รวมถึงช่วงก่อนน้ำจะหยุด เพราะยังมีการเคลื่อนที่ของน้ำอยู่ ถ้าน้ำนิ่งสนิทก็อาจเป็นช่วงพักหรือเปลี่ยนจุด

### 5.2 ความขุ่นของน้ำ

น้ำที่ **ขุ่นเล็กน้อย** มักดีกว่าน้ำใสมาก เพราะหมึกจะระวังตัวน้อยลงและมองอีจิได้ไม่ชัด

แต่ถ้าขุ่นเกินไปก็ไม่ดี เพราะหมึกมองเหยื่อไม่เห็น

ในช่วงที่หมึกตัวใหญ่กำลังวางไข่ น้ำใสเกินไปก็อาจทำให้หมึกระวังตัวมากเป็นพิเศษ

### 5.3 สาหร่ายบอกความลึก

ถ้าดึงอีจิขึ้นมาแล้วมีสาหร่ายติด แปลว่าอีจิอยู่ในแนวสาหร่ายหรือลึกเกินไป

ให้ **กรอเร็วขึ้นเล็กน้อย** เพื่อให้อีจิอยู่เหนือสาหร่าย

ในทางกลับกัน ถ้าไม่มีสาหร่ายติดเลย อาจหมายถึงอีจิอยู่สูงเกินไป ให้ **กรอช้าลงและเพิ่มจำนวนการนับ** เพื่อให้อีจิจมลึกขึ้น

จุดที่ดีที่สุดคือ **จุดที่อีจิเกือบจะติดสาหร่ายแต่ยังไม่ติด** เพราะเป็นระดับที่หมึกมักซุ่มอยู่

### 5.4 ลากอีจิขึ้นมาที่ผิวน้ำอย่างนุ่มนวล

ในช่วงท้ายของการกรอ ให้ลากอีจิขึ้นมาใกล้ผิวน้ำอย่างช้า ๆ และนุ่มนวล เพราะบางครั้งหมึกจะตามขึ้นมากัดใกล้ผิวน้ำ

### 5.5 ตารางอ่านน้ำแบบเร็ว

| สภาพที่เห็น | สัญญาณ | วิธีปรับ |
|---|---|---|
| น้ำเริ่มไหล | ผิวน้ำเริ่มมีระลอก หลังช่วงน้ำนิ่ง | เร่งค้นหาจุดและตกให้ต่อเนื่อง |
| น้ำไหลแรง | สายโค้งและอีจิถูกพาไป | ใช้อีจิหนักขึ้น ตีขึ้นต้นน้ำ และปล่อยจมช้า |
| น้ำนิ่งสนิท | ผิวน้ำเรียบเหมือนกระจก | พัก เปลี่ยนจุด หรือตกขอบน้ำลึก |
| น้ำใส | มองเห็นพื้นและตัวหมึกชัด | ใช้สีธรรมชาติ อีจิจมช้า และ curve fall |
| น้ำขุ่นเล็กน้อย | สีเขียว ๆ มองไม่เห็นพื้นชัด | ใช้สีตัด เช่น ชาร์ตหรือส้ม |
| น้ำขุ่นมาก | สีน้ำตาล ขุ่นทั้งน้ำ | ตกตื้นขึ้น ใช้สีเรืองแสง และกระตุกช้า ๆ |
| มีสาหร่ายติดอีจิ | อีจิอยู่ในแนวสาหร่าย | กรอเร็วขึ้นเล็กน้อย |
| ไม่มีสาหร่ายติดเลย | อีจิอาจอยู่สูงเกินไป | กรอช้าลงและเพิ่มการนับ |

> **เคล็ดลับเสริม:** ช่วงน้ำเริ่มไหลมักเป็นช่วงที่หมึกแอคทีฟที่สุด แต่ความแรงและระยะเวลาขึ้นกับแต่ละพื้นที่ ให้จดเวลาน้ำเริ่มเคลื่อนและเวลาที่เริ่มมีหมึกกัดไว้ จะช่วยให้วางแผนรอบต่อไปได้แม่นขึ้น

## 6. กลางวัน vs กลางคืน และการตกแบบเห็นตัว

### 6.1 กลางวันเหมาะกับการเรียนรู้

การตกกลางวันทำให้มองเห็นจุดตก เห็นอีจิ และเห็นตัวหมึกได้ง่าย จึงเหมาะกับมือใหม่ที่ต้องการเรียนรู้พฤติกรรมหมึก

แต่ในความเป็นจริง **หมึกอะโอริมักชอบแสงน้อยหรือเวลากลางคืนมากกว่า**

### 6.2 ช่วงหัวค่ำคือช่วงทอง

ในช่วงเย็นถึงหัวค่ำ หมึกที่แอคทีฟจะเริ่มออกหาอาหาร ให้ลองค้นหาชั้นกลางน้ำ

| ช่วงเวลา | ข้อดี | ข้อควรรู้ |
|---|---|---|
| กลางวัน | เห็นจุดตก เห็นอีจิ และเห็นตัวหมึก | หมึกอาจระวังตัว โดยเฉพาะน้ำใส |
| เย็น–หัวค่ำ | หมึกแอคทีฟและขึ้นมาหากินในชั้นกลางน้ำ | เป็นช่วงที่ควรใช้เวลาตกให้เต็มที่ |
| กลางคืน | หมึกชอบแสงน้อยและระวังตัวน้อยลง | ต้องอาศัยการมองสายและไฟส่องสว่าง |

### 6.3 เมื่อหมึกตามอีจิมา

ถ้าเห็นหมึกว่ายตามอีจิ ให้ทำดังนี้

1. ปล่อยอีจิจมลงอีกครั้ง
2. ค่อย ๆ ลากหรือกระตุกให้อีจิขึ้น
3. **หยุดนิ่งกะทันหัน** ตรงหน้าหมึก

หมึกที่กำลังสนใจจะกัดในจังหวะหยุดนั้น

ถ้าหมึกตามมาแล้วหยุดดู ให้ **หยุดอีจิทันที** อย่ากระตุกซ้ำ ถ้าอีจิเลยหน้าหมึกไป ให้กรอช้า ๆ กลับมาให้อยู่ในระยะที่หมึกมองเห็น แล้วหยุดอีกครั้ง

> **เคล็ดลับเสริม:** บางครั้งหมึกจะแตะหรือชนอีจิก่อนกอด ถ้ารู้สึกว่ามีน้ำหนักเบา ๆ ให้อย่ากระตุกแรง ให้ค่อย ๆ เก็บสายให้ตึงแล้วรอให้หมึกกอดแน่นก่อน

### 6.4 Sight fishing

ถ้ามองเห็นตัวหมึก ให้ตีอีจิเลยไปด้านหน้าหรือเลยตัวหมึกไปเล็กน้อย แล้วปล่อยให้จมช้า ๆ

จากนั้นกระตุกเบา ๆ ตรงหน้าหมึกแล้วหยุด หากหมึกมีแรงจูงใจ จะกัดทันที

ลำดับที่ควรทำ:

1. **มองเห็นหมึก** แล้วประเมินทิศทางที่มันหันหน้า
2. **ตีเลยตัวไปเล็กน้อย** ไม่ตีทับตัวหมึก
3. **ปล่อยอีจิจมช้า ๆ** ให้อยู่ในระดับสายตาหมึก
4. **กระตุกเบา ๆ หนึ่งครั้ง** ให้อีจิแสดงท่าทาง
5. **หยุดนิ่ง** แล้วรออย่างน้อย 3–5 วินาที
6. ถ้าหมึกยังไม่กัด ให้กระตุกเบา ๆ อีกครั้งหรือเปลี่ยนอีจิ

### 6.5 หมึกตัวใหญ่ที่เห็นอาจไม่กัด

หมึกตัวใหญ่ที่มองเห็นอาจกำลังสนใจการวางไข่และไม่สนใจเหยื่อ

บางครั้งการตกในจุดที่มองไม่เห็นตัว หรือตกตัวที่เข้ามาหาแหล่งวางไข่กลับได้ผลกว่า

นอกจากนี้ หมึกเล็กในฤดูใบไม้ร่วงมักกินอย่างหนักเพื่อเติบโต แต่หมึกใหญ่ที่อายุมากกว่าอาจตอบสนองต่ออีจิได้ช้า ต้องใช้ความอดทนและนำอีจิมาแสดงให้ดูช้า ๆ

ในคลิปมีหมึกขนาดเกิน 2 กก. ว่ายวนอยู่ในระยะที่มองเห็น แต่ไม่สนใจอีจิเลย ผู้สอนจึงเปลี่ยนไปตกตัวที่มองไม่เห็นแต่เข้ามาในพื้นที่วางไข่แทน

### 6.6 ตารางอ่านพฤติกรรมหมึกที่เห็น

| พฤติกรรม | ความหมายที่น่าจะเป็น | วิธีตอบโต้ |
|---|---|---|
| ว่ายตามห่าง ๆ | สนใจแต่ยังลังเล | หยุดอีจิหรือลากช้า ๆ |
| ตามชิดแล้วหยุดดู | กำลังตัดสินใจ | กระตุกเบา ๆ หนึ่งครั้งแล้วหยุดนิ่ง |
| แตะหรือชนอีจิ | กำลังทดสอบเหยื่อ | อย่ากระตุกแรง รอให้กอดแน่น |
| กอดแล้วปล่อยทันที | ไม่ชอบสี ขนาด หรือท่าทาง | เปลี่ยนอีจิเล็กลงหรือสีธรรมชาติขึ้น |
| หันหลังว่ายหนี | ไม่สนใจ | เปลี่ยนจุดหรือเปลี่ยนจังหวะ |
| ตัวใหญ่ไม่สนใจเลย | กำลังโฟกัสการวางไข่ | ไปตกตัวที่มองไม่เห็นหรือเปลี่ยนจุด |

> **เคล็ดลับเสริม:** การตีความพฤติกรรมเป็นเพียงแนวทาง ให้ดูทิศทางที่หมึกหันหน้าและระยะห่างประกอบ เพราะหมึกแต่ละตัวตอบสนองไม่เหมือนกัน

## 7. สู้หมึกและนำขึ้นฝั่ง

### 7.1 อย่าตวัดแรงเกินไป

เมื่อรู้สึกว่ามีน้ำหนักหรือหมึกกอดอีจิ หลายคนตื่นเต้นและตวัดคันแรงเหมือนตกปลา แต่หมึกไม่ได้กินเหยื่อแบบปลา มันใช้หนวดกอดอีจิไว้ การตวัดแรง ๆ จึงอาจทำให้ขอฉีกเนื้อหมึกหรืออีจิหลุดจากปากได้

วิธีที่ปลอดภัยกว่าคือ

1. **เก็บสายให้ตึงช้า ๆ** จนรู้สึกถึงน้ำหนัก
2. **ยกคันขึ้นช้า ๆ พอให้สายตึงและขอเกาะ** ไม่กระชาก
3. **ปล่อยให้ drag ทำงาน** เมื่อหมึกวิ่ง
4. **อย่าดึงสายด้วยมือ** เพราะแรงอาจเกินและสายขาด

ถ้าหมึกกัดตอนอีจิกำลังจม ให้อย่าตวัดทันที ให้เก็บสายให้ตึงแล้วยกคันอย่างนุ่มนวล

### 7.2 ตั้ง drag ให้หลวมพอ

เมื่อหมึกกัด ให้ตั้ง drag ให้หลวมพอสมควร เพื่อไม่ให้ตะขอฉีกหรือสายขาด

ถ้าหมึกหยุดดึง ให้ค่อย ๆ กรอเก็บสาย แต่ถ้าหมึกวิ่งให้ผ่อนและรอ

**วิธีตั้ง drag ง่าย ๆ:** ตั้งให้หมึกตัวใหญ่ยังดึงสายออกได้เมื่อออกแรงพอสมควร ไม่ใช่ล็อกจนสายขาดง่าย และไม่หลวมจนหมึกหนีได้ง่าย

### 7.3 ประคองการต่อสู้

ระหว่างสู้ ให้รักษาคันให้งอและสายให้ตึงตลอด อย่าให้สายหย่อนเพราะหมึกอาจสลัดอีจิหลุด

- หมึกอาจพุ่งออกด้านข้างหรือถอยหลังกะทันหัน ให้ผ่อน drag ตามน้ำหนัก
- อย่ายกคันสูงเกินไปจนมุมสายกับขอไม่ดี
- ถ้าหมึกมุ่งไปทางหินหรือโครงสร้าง ให้ใช้แรงดันด้านข้างค่อย ๆ บังคับทิศทาง
- เมื่อหมึกใกล้ผิวน้ำ ให้เตรียมสวิงและอย่ารีบยกขึ้น

> **เคล็ดลับเสริม:** หมึกอาจพ่นหมึกใส่ขณะต่อสู้ ควรใส่เสื้อผ้าที่ซักง่ายและระวังหมึกกระเด็นเข้าตา

### 7.4 ตักหมึกจากด้านหลัง

หมึกมักว่ายถอยหลังหรือพุ่งตัวถอยหลัง เวลาจะตักด้วยสวิง ให้ตักจากด้านหลังของหมึก จะง่ายและปลอดภัยกว่า

วิธีตักที่ง่ายที่สุดคือ **จุ่มสวิงลงน้ำก่อน** แล้วค่อย ๆ ลากหมึกให้เข้ามาเหนือปากสวิง จากนั้นยกสวิงขึ้นพร้อมกัน ไม่ใช่ไล่ตักจากด้านหน้าเพราะหมึกจะพุ่งถอยหลังหนี

### 7.5 อย่าแช่หมึกในน้ำจืด

หมึกจะเปลี่ยนสีเป็นขาวและเสียคุณภาพถ้าแช่ในน้ำจืด

ให้เก็บในกล่องเย็นโดยใช้น้ำทะเลหรือน้ำแข็งที่สะอาด และล้างด้วยน้ำทะเลก่อนเก็บ

**ขั้นตอนเก็บหมึกให้สด:**

1. ล้างเมือกและทรายด้วยน้ำทะเลสะอาด
2. ซับให้หมาดแล้ววางในกล่องเย็นที่รองด้วยน้ำแข็ง
3. ไม่แช่ในน้ำจืดและไม่ปล่อยให้โดนแดด
4. ระบายน้ำแข็งที่ละลายออก เพื่อไม่ให้หมึกแช่ในน้ำเน่า
5. ถ้าจะรับประทานทันที ให้ทำความสะอาดและแช่เย็นต่อ

> **เคล็ดลับเสริม:** การทำให้หมึกเสียชีวิตเร็วและแช่เย็นทันทีช่วยรักษาเนื้อให้ใสและหวานขึ้น แต่ต้องทำอย่างระมัดระวังไม่ให้หมึกกระเด็นหรือหนวดพันมือ

### 7.6 ปล่อยหมึกเล็กและแม่หมึกวางไข่

หมึกขนาดเล็กที่ไม่ได้บาดเจ็บรุนแรงควรปล่อยกลับ เพื่อให้เติบโตและวางไข่ต่อไป

แต่ถ้าหมึกกัดตะขอลึกจนไม่น่าอยู่รอด การเก็บไว้รับประทานก็เป็นทางเลือกที่สมเหตุสมผล

ในคลิป หมึกเล็กตัวที่ได้ถูกขอเกี่ยวลึก จึงเก็บไว้รับประทานแทนการปล่อย

## 8. กลยุทธ์: เน้นจำนวนหรือเน้นตัวใหญ่

### 8.1 อยากได้จำนวน → เดินหาหลายจุด

ถ้าเป้าหมายคือได้หมึกหลายตัว ให้เดินหาหลาย ๆ จุด ครอบพื้นที่กว้าง และตีหลายครั้ง

วิธีนี้เหมาะกับช่วงที่หมึกกระจายตัวหรือมีจำนวนมาก เพราะการครอบพื้นที่กว้างจะเจอหมึกที่กระจายอยู่ได้มากกว่าและทำให้ได้จำนวนรวมดีกว่าอยู่จุดเดียว

### 8.2 อยากได้ตัวใหญ่ → เลือกจุดดีแล้วรอ

ถ้าเป้าหมายคือหมึกตัวใหญ่ โดยเฉพาะในฤดูใบไม้ผลิ ให้เลือกจุดที่ดีที่สุดแล้ว **รอและตกอย่างใจเย็น**

หมึกใหญ่มีจำนวนน้อยกว่า การเดินหาจุดไปเรื่อย ๆ อาจไม่คุ้มเท่าการอยู่จุดที่ดีและรอจังหวะ

ในคลิป หมึกตัวใหญ่ที่ได้ตอนท้ายหนักประมาณ **2.5 กก.** ต้องใช้ drag หลวมและตักจากด้านหลังจึงนำขึ้นได้ปลอดภัย

### 8.3 ฤดูใบไม้ผลิ vs ฤดูใบไม้ร่วง

- **ฤดูใบไม้ผลิ** มีหมึกตัวใหญ่เข้ามาวางไข่ ใช้เวลาและความอดทนสูง แต่ได้ตัวใหญ่
- **ฤดูใบไม้ร่วง** มีหมึกเล็กถึงกลางที่แอคทีฟมากกว่า เหมาะกับการเก็บจำนวนและเรียนรู้

### 8.4 ตารางเปรียบเทียบสองกลยุทธ์

| เป้าหมาย | วิธีเดินจุด | ขนาดอีจิ | จังหวะ | ฤดู / เวลา |
|---|---|---|---|---|
| เน้นจำนวน | หลายจุด ครอบพื้นที่กว้าง ตีจุดละไม่นาน | 2.5–3.0 | กระตุกเร็ว สลับหยุดสั้น | ฤดูใบไม้ร่วง / หัวค่ำ |
| เน้นตัวใหญ่ | เลือกจุดดีที่สุดแล้วรออยู่จุดเดิม | 3.0–3.5 | ช้า, curve fall, หยุดนาน | ฤดูใบไม้ผลิ / เช้ามืด–หัวค่ำ |
| เน้นเรียนรู้ | จุดตื้นและปลายเขื่อนที่มองเห็นง่าย | 3.0 | ปกติตามคลิป | กลางวัน |

**หลักจำง่าย:** อยากได้จำนวนให้ **ขยับและครอบพื้นที่** อยากได้ตัวใหญ่ให้ **เลือกจุดและอดทนรอ** อย่าเอากลยุทธ์สองแบบมาผสมกันจนไม่ได้ทั้งจำนวนและขนาด

## 9. บทเรียน 10 ข้อที่เอาไปใช้ได้ทันที

1. **เช็กโคนเขื่อน มุมเขื่อน ปลายเขื่อน และร่องน้ำ** ก่อนมองจุดไกล
2. **อย่าตึงและอย่าหย่อนสายเกินไป** ปล่อยให้อีจิจมอย่างเป็นธรรมชาติ
3. **กระตุกทุกประมาณ 10 วินาที** และต้องมีจังหวะหยุดให้หมึกตัดสินใจ
4. **หลังได้หมึกกลับไปที่ระดับเดิม** เพราะหมึกมักอยู่ชั้นเดียวกัน
5. **จับจังหวะน้ำเริ่มไหล** เพราะเป็นช่วงที่หมึกแอคทีฟ
6. **อ่านสาหร่าย** เพื่อปรับความเร็วและระดับความลึกของอีจิ
7. **เห็นหมึกให้ตีเลยไปด้านหน้า แล้วหยุดนิ่ง** อย่าตีทับตัวมัน
8. **ตั้ง drag ให้หลวมและอย่าตวัดแรง** เพราะหมึกกอดอีจิด้วยหนวด ไม่ได้กินแบบปลา
9. **ตักหมึกจากด้านหลัง** เพราะหมึกมักพุ่งถอยหลังเมื่อตกใจ
10. **เก็บหมึกในน้ำทะเลและน้ำแข็ง** อย่าแช่น้ำจืด และปล่อยหมึกเล็กหรือแม่หมึกวางไข่เมื่อทำได้

## 10. ปรับใช้กับเมืองไทยได้ยังไง?

อีจิ้งในญี่ปุ่นเน้นหมึกอะโอริ แต่หลักคิดใช้ได้กับหมึกในบ้านเรา เช่น **หมึกกล้วย หมึกกระดอง และหมึกสาย** หากปรับขนาดอีจิและอุปกรณ์ให้เหมาะ

### จุดตกแบบไทย ๆ

- **โคนเขื่อนหรือท่าเทียบเรือ** ที่น้ำตื้นและมีแสงไฟ
- **มุมเขื่อนหรือแนวหิน** ที่มีกระแสน้ำ
- **ปลายเขื่อนหรือหัวหิน** ที่น้ำลึก
- **ร่องน้ำเดินเรือ** และขอบร่องน้ำ
- **กองหินหรือซากโครงสร้าง** ที่หมึกใช้หลบ

### การปรับเหยื่อและวิธีเล่น

- หมึกกล้วยและหมึกกระดองในไทยอาจชอบอีจิขนาดใหญ่กว่าหรือเหยื่อที่คล้ายกุ้งมากกว่า
- การตกกลางคืนใต้แสงไฟได้ผลดีในหลายพื้นที่ เพราะแสงดึงดูดปลาเล็กและหมึก
- ใช้จังหวะกระตุกและหยุดเหมือนในคลิป แต่ปรับความเร็วตามกระแสน้ำและความลึก
- ระวังอย่าให้อีจิติดหญ้าทะเลหรือแนวปะการัง ซึ่งอาจทำให้เหยื่อเสียหรือติดแน่น

| ชนิดหมึกในไทย | อีจิที่เริ่มใช้ | จุดที่มักเจอ | ช่วงเวลา |
|---|---|---|---|
| หมึกกล้วย | 2.5–3.0 | ท่าเรือ แสงไฟ ปลายเขื่อน | กลางคืน |
| หมึกกระดอง | 3.0–3.5 | พื้นทราย แนวหญ้าทะเล | กลางคืน |
| หมึกสาย | 2.5–3.0 | กองหิน ซากโครงสร้าง | กลางคืน |

> **เคล็ดลับเสริม:** ตารางนี้เป็นแนวทางทั่วไปสำหรับน่านน้ำไทย ต้องปรับตามขนาดหมึกและสภาพพื้นที่จริง เช่น ถ้ากระแสแรงหรือน้ำลึก ให้เพิ่มขนาดอีจิและน้ำหนักเล็กน้อย

### ข้อควรระวัง

- บริเวณท่าเรือและร่องน้ำมีเรือสัญจร ควรระวังสายและเหยื่อ
- อย่าตกในเขตหวงห้ามหรือพื้นที่อนุรักษ์
- มีกฎหมายและข้อกำหนดการประมงที่เกี่ยวข้อง เช่น ขนาดต่ำสุดหรือเขตหวงห้าม ควรตรวจสอบก่อนออกตก
- ปล่อยหมึกเล็กหรือแม่หมึกที่กำลังวางไข่กลับสู่ทะเลเมื่อทำได้

- [ ] ปล่อยอีจิจมเอง ไม่ตึงและไม่หย่อนเกินไป
- [ ] นับเวลาจนถึงก้นและจำระดับความลึก
- [ ] กระตุกทุกประมาณ 10 วินาที และมีจังหวะหยุด
- [ ] สังเกตน้ำขึ้นน้ำลงและช่วงน้ำเริ่มไหล
- [ ] อ่านสาหร่ายเพื่อปรับความเร็วและความลึก
- [ ] เตรียมสวิง ผ้าเช็ดมือ ไฟฉาย และกล่องน้ำแข็ง
- [ ] เตรียมน้ำทะเลสะอาดหรือผ้าเปียกสำหรับเช็ดหมึก

- [ ] ปล่อยหมึกเล็กหรือแม่หมึกวางไข่เมื่อทำได้

## สิ่งที่ควรฝึกต่อ

- [ ] **นับเวลาจนอีจิถึงก้น** ในความลึกต่าง ๆ แล้วจดไว้เป็นตัวเลขของตัวเอง
- [ ] **ฝึกกระตุกทุก 10 วินาที** ให้เป็นจังหวะอัตโนมัติ ทั้งแบบครั้งเดียวและแบบต่อเนื่อง
- [ ] **ฝึกหยุดนิ่ง 3–5 วินาที** หลังกระตุก เพื่อให้รู้ว่าหมึกตอบสนองตอนหยุดหรือตอนจม
- [ ] **ฝึก curve fall** ด้วยการตึงสายเล็กน้อยตอนอีจิจม ให้เห็นความต่างของการจม
- [ ] **ฝึก sight fishing** จากการตีเลยตัวหมึกเล็กน้อยแล้วหยุดตรงหน้า
- [ ] **ฝึกตักหมึกจากด้านหลัง** โดยจุ่มสวิงรอไว้ก่อน
- [ ] **จดบันทึก** เวลา จุด น้ำขึ้นน้ำลง สีอีจิ และผลที่ได้ เพื่อสร้างรูปแบบของตัวเอง

## 12. ตารางแก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| หมึกตามแต่ไม่กัด | จังหวะเร็วเกินหรือไม่มีจังหวะหยุด | หยุดนิ่ง 3–5 วินาทีหรือลองอีจิจมช้าลง |
| หมึกกอดแล้วปล่อย | ไม่ชอบสี ขนาด หรือท่าทาง | เปลี่ยนอีจิเล็กลงหรือสีธรรมชาติขึ้น |
| กระตุกแล้วสายพันกัน | สายหย่อนหรือปลายคันสะบัดเกิน | เก็บสายให้ตึงและกระตุกสั้นลง |
| หมึกวิ่งจน drag ดังรัว | drag หลวมเกินหรือหมึกตัวใหญ่ | ผ่อนและรอให้หมึกหยุดแล้วค่อยกรอ |
| หมึกหลุดใกล้ฝั่ง | สายหย่อนหรือตวัดแรงเกิน | รักษาคันให้งอและอย่าให้สายหย่อน |
| หมึกเปลี่ยนสีขาว | แช่ในน้ำจืด | ใช้น้ำทะเลล้างและแช่ในน้ำแข็ง |
| ตกจุดเดิมนานไม่มีหมึก | หมดช่วงน้ำหรือจุดไม่เหมาะ | เปลี่ยนจุดหรือพักจนน้ำเริ่มไหล |

> **เคล็ดลับเสริม:** ถ้าแก้ตามตารางแล้วยังไม่เจอสาเหตุ ให้เปลี่ยนทีละอย่างเท่านั้น (สี ขนาด หรือจังหวะ) เพื่อให้รู้ว่าอะไรคือตัวที่ทำให้หมึกกัด
