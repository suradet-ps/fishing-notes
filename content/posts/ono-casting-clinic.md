> **大野ゆうき　キャスティングライブ　2018年フィッシングショー横浜にて**
> ช่อง **富 見司サブ** · ความยาว 33:27 · เผยแพร่ 22 มกราคม 2018

มีคลิปสัมมนาตกปลาอยู่คลิปหนึ่งที่ผมมักหยิบกลับมาดูซ้ำแล้วซ้ำเล่า ไม่ใช่เพราะมีอุปกรณ์รุ่นใหม่ที่น่าตื่นเต้น หรือมีท่วงท่าการตีเหยื่อที่ผาดโผนจนดูแปลกตา แต่เพราะมันเป็นบทเรียนที่กระตุกความคิดให้เราต้องหันกลับมาตั้งคำถามกับตัวเองว่า: **"คันเบ็ดที่เราถืออยู่ในมือตอนนี้ ได้รับการปรับแต่งและเลือกใช้ให้สอดคล้องกับสภาพหมายที่เรายืนอยู่จริงแล้วหรือยัง?"**

คลิปนั้นคือบันทึกการบรรยายสดบนเวทีกลางฮอลล์ศูนย์ประชุม **Pacifico Yokohama** ในงานมหกรรมอุปกรณ์ตกปลา **Japan Fishing Show 2018** ผู้ชมยืนเบียดเสียดกันแน่นขนัดรอบเวทีสีน้ำเงิน ด้านหลังมีจอโปรเจกเตอร์ขนาดใหญ่คอยฉายภาพโคลสอัพการเคลื่อนไหวของข้อมือและรอก ชายหนุ่มที่ยืนอยู่บนเวทีในชุดทีม DAIWA พร้อมคันเบทคาสติ้งขนาดยาวในมือ คือ **โอโนะ ยูคิ (大野ゆうき - Yuki Ono)** โปรแองเกลอร์ระดับแถวหน้าของญี่ปุ่น

ในวงการตกปลาซีบาส (ปลากะพงขาวญี่ปุ่น) เขาได้รับฉายาว่า **"เจ้าชายแห่งวานโอ" (湾奥のプリンス - Prince of the Inner Bay)** คำว่า **湾奥 (Wan-ō)** หมายถึงพื้นที่ส่วนในสุดของอ่าวโตเกียว ซึ่งรายล้อมไปด้วยมหานคร ตึกระฟ้า แม่น้ำสายสั้น คลองส่งน้ำ และเขื่อนคอนกรีตกันตลิ่ง โอโนะเติบโตและฝึกฝนวิชาตกปลาในสมรภูมิน้ำกร่อยในเมืองมาตั้งแต่อายุ 13 ปี ประสบการณ์ที่เคี่ยวกรำท่ามกลางพื้นที่แคบและอุปสรรคหนาแน่น ทำให้คำสอนเรื่องการแคสติ้งของเขาเต็มไปด้วยความเฉียบคม สัจธรรมทางฟิสิกส์ และการใช้งานได้จริงในสนามรบของนักตกปลาเมือง

**ภาพที่ 1:** บรรยากาศบนเวที Pacifico Yokohama ในงาน Japan Fishing Show 2018 โอโนะ ยูคิ ถ่ายทอดศาสตร์การแคสติ้งในพื้นที่จำกัด

## 1. สมรภูมิเมือง: พื้นที่ที่ไม่ได้ถูกออกแบบมาเพื่อการแคสต์

หมายตกปลาของโอโนะไม่ใช่แนวชายฝั่งทะเลเปิดหรือแนวโขดหินกว้างใหญ่ที่นักตกปลาสามารถเงื้อคันสุดแขนแล้วหวดเหยื่อได้รอบทิศทาง 360 องศา

แม่น้ำสายหลักที่เขาพูดถึงในคลิป ได้แก่ **แม่น้ำเอโดะสายเก่า (旧江戸川)**, **แม่น้ำนากะ (中川)** และ **แม่น้ำสุมิดะ (隅田川)** ซึ่งไหลผ่านใจกลางโตเกียวลงสู่อ่าว สภาพทางกายภาพของแม่น้ำเหล่านี้ถูกควบคุมด้วยวิศวกรรมชลประทาน:
* ช่วงแม่น้ำเอโดะสายเก่ามีแนวเขื่อนตลิ่งต่ำที่พอจะเดินลงไปชิดขอบน้ำได้
* ขณะที่แม่น้ำนากะและแม่น้ำสุมิดะเป็น **แนวเขื่อนคอนกรีตตั้งฉากทรงสูง (High Vertical Revetments / 護岸 - Gogan)** ที่นักตกปลาจำเป็นต้องยืนตีจากบนสันเขื่อนคอนกรีตลงไปเท่านั้น
* บริเวณโดยรอบเต็มไปด้วยตอม่อสะพาน โครงสร้างเหล็ก ชายคา ท่อระบายน้ำ แนวต้นไม้ริมทาง ราวกั้นเหล็ก และที่สำคัญคือ **คนเดินถนน นักวิ่งจ็อกกิ้ง และคนปั่นจักรยาน** ที่สัญจรไปมาด้านหลัง

ในสภาพแวดล้อมเช่นนี้ คุณไม่มี "พื้นที่ว่างด้านหลัง (Back Space)" สำหรับเงื้อคันเบ็ดขนาดยาวแบบในตำราตกปลาชายฝั่งทั่วไป โอโนะจึงย้ำเตือนด้วยข้อคิดสำคัญว่า:

> **"ในหมายเขตเมือง คันเบ็ดที่ดีที่สุดไม่ใช่คันที่ตีได้ไกลที่สุดในแคตตาล็อก แต่เป็นคันที่คล่องตัวในการควบคุมในพื้นที่แคบ (Maneuverability) และสามารถสลับเปลี่ยนท่าแคสต์เพื่อหลบหลีกอุปสรรคได้อย่างรวดเร็ว"**

## 2. ด้ามคันที่ยาวเกินไป: อุปสรรคที่ขัดขวางจังหวะคุมเหยื่อ

ช่วงที่น่าสนใจที่สุดของคลิป คือตอนที่โอโนะหยิบคันเบ็ดขึ้นมาแล้วพลิกส่วน **ด้ามจับด้านหลัง (Rear Grip / Grip End)** ให้ผู้ชมดูอย่างละเอียด

ในตลาดอุปกรณ์ตกปลา คันเบ็ดขนาดยาวมักถูกออกแบบให้มีด้ามจับด้านหลังที่ยาวเป็นพิเศษ เพราะมันดูสง่างาม มีพลัง และช่วยให้การจับสองมือเพื่อหวดทำระยะไกลทำได้ถนัด แต่สำหรับเกมตกปลาในเมือง โอโนะชี้ให้เห็นว่า **ด้ามคันที่ยาวเกินสรีระ จะกลายเป็นอุปสรรคอันตรายที่ทำลายเกมตกปลาของคุณโดยไม่รู้ตัว**

```
[ ด้ามยาวเกินไป ] --> ชนท้องแขน / ติดราวนม / ข้อมือหมุนไม่สุด --> ก้มปลายคันช้าไป 1 วินาที!
                     --> เหยื่อจมหลุดโซน หรือเหยื่อปลั๊กเสียแอ็กชันตั้งแต่ก้าวแรก
```

### อันตรายของด้ามยาวเชิงสรีรวิทยา
1. **ล็อคข้อต่อข้อมือ:** เมื่อคุณถือรอกแล้วพยายามตวัดข้อมือเพื่อแคสต์เหยื่อ ปลายด้ามที่ยาวเกินไปจะเหวี่ยงมาชนปะทะกับท้องแขนท่อนล่าง (Forearm) หรือข้อศอก ทำให้ข้อมือไม่สามารถพับหมุนได้อย่างอิสระ ส่งผลให้มุมแคสต์แคบลงและความเร็วปลายคันลดลง
2. **ก้มปลายคันได้ช้า (The 1-Second Penalty):** เมื่อเหยื่อตกกระทบน้ำ (Chakusui - 着水) นักตกปลาจำเป็นต้อง **ลดปลายคันเบ็ดลงสู่ผิวน้ำทันที** เพื่อควบคุมสายและเริ่มกรอเหยื่อในระดับความลึกที่ถูกต้อง หากด้ามคันยาวเกินไป ปลายด้ามจะไปติดขัดกับเสื้อชูชีพ (Wader Vest), ติดขอบสันเขื่อนคอนกรีต หรือจุ่มลงไปขัดกับผิวน้ำ ทำให้คุณลดปลายคันลงช้าไปเพียง 1 วินาที

### ผลกระทบต่อแอ็กชันเหยื่อ
* **Sinking Pencil (ซิงกิ้งเพนซิล):** เหยื่อประเภทนี้ไม่มีลิ้นและอาศัยแรงยกของกระแสน้ำ หากก้มคันช้า สายหน้าจะถูกลมพัดโก่ง และเหยื่อจะจมดิ่งหลุดลงไปลึกกว่าระดับชั้นน้ำ (Range) 10–20 ซม. ที่ฝูงซีบาสกำลังลอยตัวดักซุ่มอยู่
* **Floating Minnow (มินโนว์ผิวน้ำ):** หากปลายคันยังค้างอยู่สูงในวินาทีแรกที่เริ่มกรอ แรงดึงที่ทำมุมเฉียงขึ้นจะทำให้เหยื่อเสียสมดุล ว่ายแฉลบ หรือหลุดออกจากชั้นน้ำเป้าหมาย

> **กฎการวัดความยาวด้ามของโอโนะ:** เมื่อจับรอกในท่าเตรียมตี ปลายด้ามคันเบ็ด (Grip End) จะต้องมีความยาวพอดีและ **ไม่ชนปะทะกับท้องแขนในขณะที่บิดข้อมืออย่างเต็มองศา** อุปกรณ์ที่ดีต้องรับใช้สรีระของผู้ตก ไม่ใช่บีบให้ร่างกายต้องปรับตัวเข้าหาอุปกรณ์

![โอโนะพลิกด้ามให้ผู้ชมดูความยาว grip end บนเวที](assets/ono-casting-grip.jpg)

**ภาพที่ 2:** โอโนะพลิกด้ามคันให้เห็นความยาวของ Grip End ที่พอดีกับสรีระแขนท่อนล่าง ไม่ยาวจนชนท้องแขน

## 3. คันนุ่ม vs คันแข็ง: ศาสตร์แห่งการโหลดคัน (Rod Loading)

หัวข้อถัดมาที่โอโนะอธิบายอย่างลึกซึ้ง คือความเข้าใจผิดเรื่อง "ความแข็งของคันเบ็ด" (Rod Power / Action)

คำว่า **"การโหลดคัน" (Rod Loading / 曲げ込み)** ในทางฟิสิกส์การแคสติ้ง หมายถึง **การถ่ายทอดน้ำหนักของเหยื่อและแรงเหวี่ยง เพื่อบังคับให้แบลงก์คาร์บอนโค้งงอและกักเก็บพลังงานศักย์ยืดหยุ่น (Rod Flex / 反発力) ไว้ในเนื้อคัน** ก่อนที่จะปลดปล่อยพลังงานนั้นออกไปดีดเหยื่อพุ่งสู่อากาศ หากนักตกปลาไม่สามารถทำให้คันเบ็ดโค้งงอได้ คันเบ็ดจะทำหน้าที่เป็นเพียงแค่ "ท่อนไม้กระด้าง" ที่ไม่ช่วยส่งแรงใดๆ เลย

```
[ คันนุ่ม : Soft Blank ]  --> โค้งง่าย แต่ปลายคันสั่นสะบัด (Tip Flutter) ทิศทางเหยื่อเพี้ยน
[ คันแข็ง : Stiff Blank ] --> ถ่ายทอดความรู้สึกชัดเจน แม่นยำดั่งเลเซอร์ (ต้องโหลดคันเป็น!)
```

### การเปรียบเทียบเชิงวิศวกรรม: คันนุ่ม ปะทะ คันแข็ง

| ประเด็นเปรียบเทียบ | คันนุ่ม (Soft / Regular Action) | คันแข็ง (Stiff / Fast Action) |
|---|---|---|
| **การโหลดคัน** | โค้งงอง่าย มือใหม่หรือคนแรงน้อยก็โหลดได้ | ต้องอาศัยทักษะ จังหวะ และแรงเหวี่ยงที่เฉียบคม |
| **ระยะทาง** | ตีออกตัวง่าย แต่ตันที่ระยะกลาง | ทำระยะได้ไกลกว่ามากเมื่อโหลดสะสมพลังได้เต็มคัน |
| **ความแม่นยำ** | ปลายคันสั่นสะบัดหลังปล่อยสาย จุดตกเบี่ยงเบน | นิ่งสนิท ไร้แรงสั่นค้าง เหยื่อพุ่งเข้าเป้าแม่นยำ |
| **ความรู้สึกสัมผัส** | ความสั่นสะเทือนถูกซับทอน คล้ายการเคาะเส้นยาง | ส่งผ่านความรู้สึกจากเหยื่อคมชัด คล้ายเส้นลวดเหล็ก |
| **การวัดเบ็ด (Hookset)** | แบลงก์ยุบตัว ส่งแรงดันคมเบ็ดเข้ากระดูกปลาได้ช้า | ส่งแรงทะลุทะลวงสูง คมเบ็ดฝังลึกได้ทันที |

โอโนะเปิดเผยว่า ในเกมซีบาสเมือง เขาเลือกใช้ **คันที่มีความแข็งค่อนข้างสูง (Medium-Heavy ถึง Heavy Fast)** เพราะในระยะทำการ **50–60 เมตร** คันแข็งช่วยให้เขาส่งเหยื่อแหวกกระแสลมได้อย่างแม่นยำและสัมผัสแรงสะกิดของปลาได้ในเสี้ยววินาที 

อย่างไรก็ตาม เขาเตือนอย่างจริงใจว่า อย่าเพิ่งซื้อคันแข็งตามโปร เพียงเพราะเห็นว่าโปรตีได้ไกล หากคุณยังไม่มีทักษะและแรงพอที่จะบีบให้คันแข็งโค้งตัวได้ การเริ่มต้นจากคันที่มีความนุ่มปานกลางจะช่วยให้คุณเรียนรู้สัมผัสการโหลดสปริงได้เร็วกว่า

![จังหวะปล่อยคันหลังโหลดในคลิป](assets/ono-casting-load.jpg)

**ภาพที่ 3:** จังหวะการปลดปล่อยพลังงานหลังการโหลดคันเบ็ดอย่างเต็มที่ ซึ่งต้องอาศัยจังหวะและการส่งแรงที่สมบูรณ์แบบ

## 4. Overhead Cast ที่แท้จริงคือ Three-Quarter Cast

เมื่อเข้าสู่ท่วงท่าการแคสต์ โอโนะเริ่มต้นจากท่ามาตรฐานที่ทุกคนคิดว่าตัวเองคุ้นเคยที่สุด นั่นคือ **Overhead Cast (การตีเหนือศีรษะ)**

ข้อผิดพลาดที่เขาพบบ่อยที่สุดในหมู่นักตกปลา คืออาการ **"ตีด้วยปลายคันเพียงอย่างเดียว" (Tip-Only Flicking)** นั่นคือการง้างคันสั้นๆ อยู่ด้านหน้า แล้วใช้ข้อมือสะบัดเฉพาะส่วนปลายคันให้ดีดไปข้างหน้า ผลลัพธ์คือแบลงก์ท่อนล่างและโคนคัน (Butt Section) ไม่ได้โค้งงอเลยแม้แต่น้อย เหยื่อไม่ได้รับแรงส่ง และหากใช้เหยื่อที่มีน้ำหนักมาก ปลายคันท็อปไกด์อาจหักสะบั้นได้ง่าย

### ความจริงทางกายวิภาค: ไม่มีใครตวัดคันแนวดิ่ง 90 องศาได้จริง
โอโนะชี้ให้เห็นความจริงที่น่าทึ่งว่า ในทางปฏิบัติ มนุษย์ไม่สามารถวาดคันเบ็ดขนาดยาวลงมาตรงๆ ผ่ากลางกึ่งกลางศีรษะได้อย่างมีพลังโดยไม่เอียงตัว ท่า Overhead ที่เป็นธรรมชาติและทรงพลังที่สุดจึงแท้จริงแล้วคือ **Three-Quarter Cast (การตีเฉียงทำมุมประมาณ 3 ส่วน หรือ 45–60 องศา)**

```
   (1) เปิดลำตัวเล็กน้อย         (2) ง้างคันไปด้านหลังให้ลึก         (3) โคนคันรับน้ำหนักเต็มที่         (4) ปลดปล่อยสปริง
        [ Open Stance ]                  [ Deep Draw ]                    [ Butt Loading ]                [ Full Release ]
```

### เคล็ดลับ "ยืดสโตรกสปริงให้ยาวที่สุด"
* ยืนในท่าที่มั่นคง เปิดปลายเท้าและลำตัวเล็กน้อย
* ง้างคันเบ็ดเฉียงขึ้นไปด้านหลังให้ลึก ดุจดั่งการน้าวสายธนู (Deep Stroke) เพื่อให้ตัวเหยื่อดึงให้แบลงก์โค้งตัวตั้งแต่โคนคัน
* ออกแรงเร่งความเร็วอย่างต่อเนื่องจากด้านหลังมาข้างหน้า ให้ทั้งลำตัวคันรับภาระน้ำหนักร่วมกัน
* การยืดช่วงสโตรกการเหวี่ยงให้ยาวขึ้น จะช่วยสะสมพลังงานได้มหาศาล เหยื่อจะพุ่งทะยานออกไปได้ระยะทางไกลลิบโดยที่นักตกปลาไม่ต้องออกแรงกระชากกล้ามเนื้อแขนเลย

**ภาพที่ 4:** ท่า Three-Quarter Cast ที่เปิดลำตัวและยืดสโตรกไปด้านหลังอย่างลึกซึ้ง เพื่อโหลดพลังงานเข้าสู่โคนคัน

## 5. Backhand Underarm: นวัตกรรมใช้ปลายด้ามแนบแขนเป็นจุดหมุน

นี่คือ **"ท่าไม้ตายประจำตัว" (Signature Move)** ที่ทำให้ชื่อของ โอโนะ ยูคิ โด่งดังไปทั่วประเทศญี่ปุ่น: **Backhand Underarm Cast**

ในหมายที่มีสิ่งกีดขวางเหนือศีรษะ (เช่น ใต้สะพาน ชายคาคอนกรีต หรือกิ่งไม้รกทึบ) และด้านหลังมีกำแพงเขื่อนขวางกั้นจนไม่สามารถเงื้อคันได้ การใช้ท่า Overhead ย่อมเป็นไปไม่ได้ นักตกปลาสายแบสอาจคุ้นเคยกับการสะบัดข้อมือข้างเดียว แต่สำหรับคันซีบาสที่มีความยาว 8 ถึง 9 ฟุตขึ้นไป และรอกที่มีน้ำหนักมากกว่า การใช้แรงข้อมือเพียวๆ จะทำให้ข้อมือบาดเจ็บ ควบคุมทิศทางไม่ได้ และทำให้รอกเบทเกิดสายฟู่ทันที

### ความลับของจุดหมุน: แนบ Grip End เข้ากับท้องแขน
โอโนะแก้ปัญหานี้ด้วยหลักการคานดีดคานงัดอันแยบยล โดยการ **นำปลายด้ามคันเบ็ด (Grip End) แนบชิดเข้ากับท้องแขนท่อนล่างด้านใน (Forearm) ให้มั่นคง**

```
[ Grip End แนบท้องแขน ]  --> กลายเป็น "จุดหมุนคงที่" (Fixed Pivot)
                             ข้อมือสะบัดสั้นๆ เพียงเล็กน้อย --> ปลายคันสะบัดดีดด้วยความเร็วสูง 200%!
```

1. เมื่อปลายด้ามถูกล็อคแนบกับแขน แขนท่อนล่างและด้ามคันจะกลายเป็นแกนเดียวกัน เกิดเป็นจุดหมุนที่มั่นคง
2. เพียงแค่สะบัดข้อมือเบาๆ ในระยะสั้นๆ แรงส่งจะถูกทวีคูณ ส่งผลให้ปลายคันเบ็ดโค้งตัวและดีดตัวกลับด้วยความเร็วสูงเป็นสองเท่า
3. วิถีของเหยื่อจะพุ่งแหวกอากาศออกไปในระนาบขนานกับแนวกำแพงเขื่อนคอนกรีตในระยะ **40 เมตรได้อย่างง่ายดาย** โดยที่นักตกปลาไม่จำเป็นต้องถอยห่างจากกำแพงเลยแม้แต่ก้าวเดียว

## 6. Forehand Cast และการใช้มือซ้ายเป็นระบบเบรกสองจังหวะ

อีกด้านหนึ่งของท่าใต้แขนคือ **Forehand Underarm Cast** ซึ่งเมื่อนำมาผสานเข้ากับท่า Backhand จะทำให้นักตกปลาสามารถ **ครอบคลุมองศาการส่งเหยื่อได้กว้างถึง 180 องศา** จากจุดยืนจุดเดียวบนสันเขื่อนโดยไม่ต้องขยับเท้า

ความลับที่ลึกซึ้งที่สุดของท่า Forehand อยู่ที่ **"บทบาทของมือซ้าย"**

### ศิลปะการเบรกสายสองจังหวะ (Dual-Stage Braking)
ในจังหวะที่เหยื่อพุ่งออกไปสู่เป้าหมาย หากปล่อยให้นิ้วโป้งหรือนิ้วชี้ข้างที่ถือคันควบคุมการหยุดสายเพียงอย่างเดียว ความละเอียดในการชะลอเหยื่อจะมีจำกัด แต่โอโนะใช้ **มือซ้ายเข้ามาช่วยแตะสปูลหรือขอบสายแบบ 2 จังหวะ**:

```
[ จังหวะที่ 1 : แตะชะลอ ]  --> มือซ้ายแตะสายเบาๆ จัดระเบียบวิถีเหยื่อให้ตรงแนวเล็ง
[ จังหวะที่ 2 : ล็อคแม่นยำ ] --> กดหยุดสายสนิทเมื่อเหยื่อลอยถึงเป้าหมาย เหยื่อลงน้ำเงียบกริบ
```

1. **จังหวะที่ 1 (แตะชะลอ):** เมื่อเหยื่อพุ่งไปได้ประมาณ 80% ของระยะทาง มือซ้ายจะยื่นไปแตะสปูลเบาๆ เพื่อตัดความเร็วส่วนเกินและปรับระนาบวิถีของเหยื่อให้ตรงเป้าหมาย
2. **จังหวะที่ 2 (ล็อคหยุด):** เมื่อเหยื่อลอยไปแตะตำแหน่งหน้าตอม่อหรือตลิ่งห่างเพียงไม่กี่เซนติเมตร มือซ้ายจะกดล็อคสายทันที เหยื่อจะทิ้งตัวลงสู่ผิวน้ำอย่างแผ่วเบา ไร้เสียงรบกวน และไม่เสี่ยงต่อการพุ่งชนโครงสร้างคอนกรีตจนเหยื่อแตกหัก

มือซ้ายของโอโนะจึงไม่ได้ทำหน้าที่เพียงแค่ประคองรอก แต่มันคือ **"ทั้งระบบเบรก ABS และศูนย์เล็งอัจฉริยะ"** ที่ช่วยให้การวางเหยื่อในจุดอันตรายมีความแม่นยำสูงสุด

![จังหวะ forehand วิถีต่ำในคลิป](assets/ono-casting-forehand.jpg)

**ภาพที่ 6:** ท่า Forehand Cast วิถีต่ำ ส่งเหยื่อเลียดผิวน้ำขนานไปกับแนวสิ่งกีดขวาง

![ภาพระยะใกล้ของมือและรอกระหว่างอธิบายการใช้มือซ้ายหยุดสาย](assets/ono-casting-brake.jpg)

## 7. ลมข้างและศิลปะการยิงเหยื่อวิถีพุ่งต่ำ (Low Trajectory)

ในการสาธิตสดบนเวที เกิดกระแสลมปรับอากาศพัดจากด้านซ้ายตัดผ่านหน้าเวทีอย่างรุนแรง โอโนะจึงฉวยโอกาสนี้สาธิตให้เห็นความแตกต่างของวิถีเหยื่อ:
* เมื่อเขาตีด้วยท่า **Overhead Cast สูงตามปกติ:** สายเอ็นลอยเคว้งอยู่ในอากาศนาน แรงลมปะทะเข้ากับสายทำให้สายโก่งเป็นหางว่าว (Line Belly) พัดพาเหยื่อปลิวเบี่ยงออกนอกเป้าหมายไปทางขวาอย่างชัดเจน
* เมื่อเขาสลับมาใช้ท่า **Underarm วิถีต่ำ (Low Trajectory):** เขาย่อตัวลงเล็กน้อย ส่งเหยื่อพุ่งเลียดขนานไปกับพื้นเวที สายเอ็นอยู่ในระดับต่ำจึงไม่ถูกลมพัดพา เหยื่อพุ่งเข้าเป้าหมายอย่างตรงแหน็ว และสายหน้าตึงกระชับพร้อมใช้งานทันที

### การย่อตัวและเทคนิค "เชิดปลายคันส่งเหยื่อ"
เมื่อต้องส่งเหยื่อลอดใต้สิ่งกีดขวางเตี้ยๆ โอโนะแนะนำให้ **ย่อตัวลงเพื่อลดระดับปล่อยเหยื่อให้ขนานกับผิวน้ำ** ทันทีที่เหยื่อพุ่งหลุดออกจากคัน ให้เชิดปลายคันขึ้นเบาๆ เพื่อให้เหยื่อลอยตัวขึ้นสู่จุดสูงสุดในมุมระนาบราบเรียบ แล้วค่อยๆ ร่อนลงสู่ผิวน้ำอย่างนิ่มนวล

> **สัจธรรมของโอโนะ:** "มือใหม่มักคิดว่าถ้าอยากตีให้ไกลต้องเงื้อคันให้สูงและออกแรงให้มากที่สุด แต่ในพื้นที่แคบและลมแรง การอยากตีให้แม่นและได้ระยะ คุณต้องเริ่มต้นจากการปล่อยเหยื่อให้ต่ำที่สุด"

## 8. ฤดูกาล "บาจิ นุเกะ" (Bachi Nuke): เมื่อความเร็วในการตีซ้ำ (Te-kaeshi) คือตัวชี้วัด

ช่วงหนึ่งของการบรรยาย โอโนะได้ยกตัวอย่างฤดูกาลสำคัญของอ่าวโตเกียว นั่นคือ **บาจิ นุเกะ (バチ抜け - Bachi Nuke)** ซึ่งเป็นปรากฏการณ์ที่หนอนทะเลและไส้เดือนทะเลพร้อมใจกันลอยตัวขึ้นมาผสมพันธุ์บนผิวน้ำในคืนน้ำเกิดช่วงต้นฤดูใบไม้ผลิ

ในช่วงเวลานี้ ฝูงปลาซีบาสจะลอยตัวขึ้นมาจิบกินหนอนบนผิวน้ำอย่างบ้าคลั่ง แต่ละจุดที่ปลาขึ้นน้ำ (Boil) จะเกิดขึ้นเพียงเสี้ยววินาทีแล้วจางหายไป หากคุณใช้ท่า Overhead คุณจะต้องเสียเวลายกคัน ง้างคันไปข้างหลัง และตรวจสอบพื้นที่รอบตัว ซึ่งมักทำให้พลาดโอกาสทองไปอย่างน่าเสียดาย

ท่าแคสต์ใต้แขน (Underarm Cast) จึงกลายเป็นอาวุธชี้ขาด เพราะมันมอบ **"ความเร็วในการเก็บสายและส่งเหยื่อซ้ำ" (Te-kaeshi - 手返し)** ในระดับสูงสุด เพียงแค่สะบัดข้อมือเบาๆ คุณก็สามารถส่งเหยื่อพุ่งตรงเข้าใส่จุดที่ปลาเพิ่งโผล่ขึ้นมาจิบน้ำได้ทันทีในพริบตา

## 9. ปรัชญา "Match the Bite": การแคสต์เป็นเพียงครึ่งแรกของสมการ

แม้คลิปนี้จะเน้นเรื่องการแคสติ้ง แต่โอโนะเน้นย้ำว่า การตีเหยื่อที่ยอดเยี่ยมเป็นเพียงแค่ 50% ของความสำเร็จในการตกปลา อีก 50% ที่เหลือคือการทำความเข้าใจปรัชญาประจำตัวของเขาที่เรียกว่า **"Match the Bite"**

การจับคู่จังหวะกัดของปลาประกอบด้วย 3 มิติที่ต้องทำงานสอดประสานกัน:
1. **Range (การควบคุมระดับชั้นน้ำ):** การนำเหยื่อลงไปแหวกว่ายในระดับความลึกที่ปลาเปิดปากหากิน (ไม่ใช่แค่ตีลงน้ำ)
2. **Action (แอ็กชันของเหยื่อ):** การเลือกการส่าย พลิกตัว หรือเลื้อย ให้ตรงกับชนิดของเหยื่อธรรมชาติในวันนั้น
3. **Speed (ความเร็วในการเคลื่อนที่):** การจับคู่ความเร็วในการกรอให้สอดคล้องกับอารมณ์ความกระตือรือร้นของปลา

การแคสติ้งที่สมบูรณ์แบบ จึงไม่ใช่แค่การอวดพลังว่าใครตีได้ไกลกว่า แต่คือ **"การส่งเหยื่อเข้าไปอยู่ในระดับชั้นน้ำที่ถูกต้อง (Range Control) และพร้อมเริ่มสร้างแอ็กชันที่ปลาต้องการได้ตั้งแต่รอบแรกที่หมุนรอก"**

---

## 10. มารยาทและความรับผิดชอบของนักตกปลาเมือง

ช่วงท้ายของการบรรยาย โอโนะได้ฝากข้อคิดที่สะท้อนถึงวุฒิภาวะและความรับผิดชอบต่อสังคมของนักตกปลาในเขตเมือง:

ในมหานครอย่างโตเกียว ริมแม่น้ำเป็นพื้นที่สาธารณะที่ถูกแบ่งปันร่วมกับคนทั่วไป มีทั้งเด็ก ผู้สูงอายุ คนจ็อกกิ้ง และนักปั่นจักรยาน การตีเหยื่อที่ผิดพลาดเพียงครั้งเดียว อาจนำไปสู่อุบัติเหตุร้ายแรง เช่น คมเบ็ดเกี่ยวกับผู้คน สายเอ็นพาดโดนทรัพย์สิน หรือเหยื่อปลอมฟาดเข้าใส่สะพาน

> **คำเตือนจากใจของโอโนะ:** "การทำประกันอุบัติเหตุเป็นเรื่องที่ดี แต่สิ่งที่ดีที่สุดคือการไม่ก่อให้เกิดปัญหาตั้งแต่แรก การแคสต์ที่เก่งกาจไม่ได้วัดกันที่ระยะทาง แต่วัดกันที่ความสามารถในการควบคุมเหยื่อได้ 100% รู้ว่าด้านหลังมีใครอยู่หรือไม่ และรู้จักจังหวะที่ควร 'หยุดตี' เพื่อความปลอดภัยของทุกคน"

![บรรยากาศผู้ชมรอบเวทีในงาน Fishing Show](assets/ono-casting-crowd.jpg)

**ภาพที่ 9:** บรรยากาศผู้ชมที่หนาแน่นรอบเวที ย้ำเตือนว่าในพื้นที่เมืองรอบตัวเรามักมีผู้คนร่วมใช้พื้นที่อยู่เสมอ

## 11. การนำไปปรับใช้กับแหล่งน้ำในเมืองไทย

หลักคิดและสรีรศาสตร์การแคสติ้งของโอโนะ สามารถนำมาประยุกต์ใช้กับหมายตกปลาในบ้านเราได้อย่างยอดเยี่ยม:

* **การตกปลาตามคลองในเมืองและประตูน้ำ (กทม. และปริมณฑล):** เช่น คลองแสนแสบ คลองประเวศ หรือประตูน้ำพระยาสุเรนทร์ ซึ่งเต็มไปด้วยสะพานคนข้ามและราวเหล็ก การใช้ **Backhand ล็อคด้ามแนบแขน** จะช่วยส่งเหยื่อเข้าซอกตอม่อได้อย่างปลอดภัย
* **เกมตกปลาช่อนและกระสูบตามลำรางข้างทาง:** พื้นที่มักมีกิ่งกระถินและต้นกกปกคลุม การใช้ **Three-Quarter Cast ยืดสโตรกยาว** และ **Forehand มือซ้ายเบรกสองจังหวะ** จะช่วยส่งเหยื่อเข้าหมายแคบๆ ได้โดยไม่ต้องกังวลเรื่องกิ่งไม้ด้านหลัง
* **เกมปลากะพงขังและกะพงวัง:** การปรับความยาวด้ามคันให้พอดีกับท่อนแขน ช่วยให้นักตกปลาสามารถลดปลายคันลงคุมระดับชั้นน้ำของ Sinking Pencil หรือ Minnow ได้ทันทีที่เหยื่อตกกระทบน้ำ

## 12. ตารางสรุป 8 กฎเหล็กการแคสติ้งของ โอโนะ ยูคิ

| ลำดับ | กฎเหล็ก | รายละเอียดเชิงเทคนิค |
|---|---|---|
| **1** | **เลือกคันจากหมาย** | คันที่ดีที่สุดคือคันที่คล่องตัวในพื้นที่จำกัด ไม่ใช่คันที่ยาวที่สุดในแคตตาล็อก |
| **2** | **ด้ามคันไม่เกะกะ** | ปลายด้ามต้องไม่ชนท้องแขน เพื่อเปิดให้ข้อมือหมุนได้ 360 องศา และก้มคันคุมระดับน้ำได้ทันที |
| **3** | **เข้าใจการโหลดคัน** | คันแข็งให้ความแม่นยำสูง แต่ต้องมีทักษะในการโหลดคันให้โค้งงอเพื่อสะสมแรงดีด |
| **4** | **Overhead คือ Three-Quarter** | เปิดลำตัว ยืดสโตรกไปด้านหลังให้ลึก เพื่อโหลดพลังงานลงสู่โคนคันอย่างเต็มที่ |
| **5** | **Backhand ใช้ด้ามเป็นจุดหมุน** | ล็อคปลายด้ามแนบชิดท้องแขน สะบัดข้อมือสั้นๆ แต่ได้ความเร็วปลายคันเพิ่มขึ้น 2 เท่า |
| **6** | **มือซ้ายคือเบรกสองจังหวะ** | มือซ้ายแตะชะลอความเร็วเหยื่อ แล้วกดล็อคหยุดสนิทเมื่อเหยื่อถึงเป้าหมาย |
| **7** | **ยิงวิถีต่ำเอาชนะลม** | ย่อตัวลงเพื่อปล่อยเหยื่อเลียดผิวน้ำ ตัดปัญหาลมข้างพัดสายโก่ง |
| **8** | **แคสต์เก่งคือมีมารยาท** | หันมองพื้นที่ด้านหลังทุกครั้ง ความปลอดภัยของคนรอบข้างสำคัญกว่าการได้ปลา |

## 13. ตารางคำศัพท์เทคนิคภาษาญี่ปุ่นในคลิป (Glossary)

| คำศัพท์ภาษาญี่ปุ่น | คำอ่าน (Romaji) | ความหมายในภาษาไทย |
|---|---|---|
| **スリークォーター** | Three-quarter | การตีเหยื่อเฉียงทำมุมประมาณ 45–60 องศาตามแนวสรีรวิทยา |
| **バックハンドキャスト** | Backhand Cast | การตวัดคันหลังมือใต้แขนโดยใช้ปลายด้ามเป็นจุดหมุน |
| **フォアハンドキャスト** | Forehand Cast | การตวัดคันหน้ามือใต้แขนร่วมกับการใช้มือซ้ายเบรกสาย |
| **グリップエンド** | Grip End | ปลายด้ามจับส่วนท้ายสุดของคันเบ็ด |
| **ブランク** | Blank | ตัวคันเบ็ดคาร์บอนเปล่าๆ |
| **ストローク** | Stroke | ช่วงระยะและท่วงท่าในการวาดคันเบ็ดสะสมพลังงาน |
| **曲げ込み (まげこみ)** | Magekomi / Rod Loading | การออกแรงบังคับให้คันเบ็ดโค้งงอเพื่อสะสมพลังงานสปริง |
| **着水 (ちゃくすい)** | Chakusui | วินาทีที่เหยื่อปลอมตกกระทบผิวน้ำ |
| **バチ抜け (ばちぬけ)** | Bachi-nuke | ฤดูกาลที่หนอนทะเลลอยขึ้นมาผสมพันธุ์บนผิวน้ำในต้นฤดูใบไม้ผลิ |
| **護岸 (ごがん)** | Gogan | แนวเขื่อนคอนกรีตกันตลิ่งริมแม่น้ำในเขตเมือง |
| **湾奥 (わんおう)** | Wan-ō | พื้นที่ในสุดของอ่าว (อ่าวโตเกียวตอนใน) |
| **手返し (てがえし)** | Te-kaeshi | ความเร็วและความต่อเนื่องในการเก็บสายแล้วส่งเหยื่อซ้ำ |

## 14. เช็กลิสต์ฝึกซ้อมแคสติ้งสไตล์โอโนะ (Practice Checklist)

- [ ] **เช็กด้ามจับ:** ถือรอกแล้วหมุนข้อมือ ปลายด้ามชนท้องแขนหรือติดเสื้อชูชีพหรือไม่
- [ ] **เช็กการก้มคัน:** หลังสะบัดคัน สามารถลดปลายคันลงสู่ระดับผิวน้ำได้ทันทีภายใน 1 วินาทีหรือไม่
- [ ] **เช็กการโหลด Three-Quarter:** ยืดสโตรกไปด้านหลังลึกพอจนรู้สึกถึงน้ำหนักเหยื่อดึงโคนคันหรือไม่
- [ ] **เช็ก Backhand Pivot:** ปลายด้ามแนบสนิทกับท้องแขนในจังหวะสะบัดหรือไม่
- [ ] **เช็กมือซ้ายสองจังหวะ:** ใช้มือซ้ายช่วยแตะชะลอสายและล็อคหยุดเหยื่อก่อนตกน้ำอย่างนุ่มนวล
- [ ] **เช็กพื้นที่ด้านหลัง:** หันไปตรวจดูคนเดินถนน จักรยาน และสิ่งกีดขวางก่อนเงื้อคันทุกครั้งร้อยเปอร์เซ็นต์
