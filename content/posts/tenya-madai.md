สายลมเช้าอันสดชื่นพัดผ่านท่าเรือประมง เรือตกปลาสีขาวสะอาดตาหลายลำจอดเทียบท่าเรียงรายพร้อมเสียงคลื่นกระทบกราบเรือเบา ๆ แสงแดดรำไรเริ่มสาดส่องผิวน้ำทะเลเปิด สะท้อนประกายระยิบระยับเป็นสัญญาณแห่งการเริ่มต้นวันใหม่

บนดาดฟ้าเรือลำหนึ่ง ชายในชุดเสื้อฮู้ดสีดำทะมัดทะแมงและหมวกแก๊ปยืนต้อนรับด้วยรอยยิ้มอันอบอุ่น เขาคือ **มิยาซาวะ ยูกิโนริ (宮澤幸則 - Yukinori Miyazawa)** ฟิลด์เทสเตอร์ระดับตำนานของ DAIWA และผู้เชี่ยวชาญการตกปลาจากเรือ (Boat Fishing) แถวหน้าของประเทศญี่ปุ่น ในมือของเขาไม่ได้ถือคันเบ็ดท่อนโตและรอกไฟฟ้าขนาดใหญ่เทอะทะเหมือนการตกปลาหน้าดินโบราณ หากแต่ถือคันสปินนิ่งน้ำหนักเบาเพรียวบางยาวประมาณ 2.4 เมตร ที่มีหัวตะกั่วแต้มสีตัวเล็ก ๆ เกี่ยวกับกุ้งทะเลสดห้อยอยู่ที่ปลายสาย

วันนี้มิยาซาวะตั้งใจพานักตกปลามือใหม่ทุกคนออกสู่ทะเลลึก เพื่อสัมผัสกับเสน่ห์ของ **"ฮิโตสึ เท็นยะ มาดาอิ" (ひとつテンヤマダイ - Hitotsu Tenya Madai)** ศาสตร์การตกปลากะพงแดงญี่ปุ่น (มาดาอิ) ด้วยชุดเบ็ดเท็นยะและเหยื่อกุ้งตัวเดียว เป็นเกมตกปลาทะเลที่ใช้อุปกรณ์เบาสบาย (Light Tackle) ขั้นตอนตรงไปตรงมา และให้ความรู้สึกตื่นเต้นเร้าใจคล้ายการเล่นเหยื่อปลอม ทว่าผลลัพธ์ของทริปนี้กลับงดงามเกินคาด เมื่อฝูงปลาไทสีชมพูประกายเงินขนาดต่าง ๆ รวมถึงปลาหน้าดินชั้นยอดหลากหลายสายพันธุ์ ต่างแวะเวียนขึ้นมาทักทายตลอดทั้งวัน

![มิยาซาวะ ยูกิโนริ บนเรือก่อนเริ่มตกเท็นยะมาดาอิ](assets/tenya-opening.jpg)

**ภาพที่ 1:** มิยาซาวะ ยูกิโนริ บนเรือตกปลาก่อนออกเดินทางสู่หมาย พร้อมชุดอุปกรณ์เท็นยะมาดาอิขนาดกะทัดรัด

## 1. ศาสตร์แห่งเท็นยะ: เมื่อภูมิปัญญาดั้งเดิมผสานความรู้สึกแบบเหยื่อปลอม

เพื่อเริ่มก้าวแรกอย่างมั่นใจ เราต้องทำความเข้าใจก่อนว่า **เท็นยะ (テンヤ - Tenya)** คืออะไร ในทางประวัติศาสตร์ เท็นยะคือหัวตะกั่วถ่วงน้ำหนักทรงสามเหลี่ยมหรือทรงกรวยที่มีตัวเบ็ดหลักฝังติดแน่นอยู่กับหัวตะกั่ว เป็นภูมิปัญญาชาวประมงพื้นบ้านดั้งเดิมที่ถือกำเนิดขึ้นบริเวณชายฝั่ง **โอฮาระ (大原 - Ohara) ในจังหวัดชิบะ** สำหรับใช้เกี่ยวกุ้งสดหย่อนลงไปหลอกล่อ **มาดาอิ (マダイ - Madai)** หรือปลากะพงแดงญี่ปุ่น ซึ่งได้รับการยกย่องให้เป็น "ราชาแห่งปลาทะเล" (King of Saltwater Fish) ของญี่ปุ่น ทั้งในแง่ความงดงาม รสชาติอันโอชะ และความมงคล

สิ่งที่ทำให้เท็นยะมาดาอิในยุคปัจจุบันได้รับความนิยมอย่างถล่มทลาย จนนักตกปลาสายลูเร่ (Lure Fishing) พากันหลงใหล คือการตัดทอนอุปกรณ์ขนาดใหญ่ทิ้งไป แล้วแทนที่ด้วยชุดเบ็ดน้ำหนักเบา (Light Tackle) สาย PE เส้นเล็ก และการสร้างแอ็กชันที่ต้องอาศัยจังหวะสองมือของนักตกปลาเอง:

```
[วงจรจังหวะเท็นยะมาดาอิ]
1. หย่อนเหยื่อลงสู่หน้าดิน (着底 - Chakutei)
2. ยกคันขึ้นหนึ่งครั้งอย่างนุ่มนวลและเฉียบคม (Lift / Shakuri)
3. ปล่อยให้เท็นยะร่อนจมลงอย่างเป็นธรรมชาติ (Tension Fall)
4. ปลามักพุ่งเข้าชาร์จเหยื่อในจังหวะ "กำลังร่วงหล่น" (On the Fall)
5. สัมผัสแรงสะกิด วัดคันเบ็ดสวนทันที แล้วสู้ปลาด้วยระบบเบรกที่ราบเรียบ
```

แม้ว่าตัวเหยื่อที่ใช้จะเป็นกุ้งจริง แต่กลไกการกระตุ้นสัญชาตญาณ การอ่านสัมผัสปลายสาย และการควบคุมระดับการจมน้ำกลับให้อารมณ์เหมือนการเล่นเหยื่อปลอมร้อยเปอร์เซ็นต์ มือใหม่จึงสามารถเรียนรู้และเพลิดเพลินได้ทันทีโดยไม่ต้องพกอุปกรณ์หนัก ๆ ให้เมื่อยล้า

## 2. ทำไมเกมเท็นยะถึงเป็นตัวเลือกที่ดีที่สุดสำหรับมือใหม่หัดลงเรือ?

การเริ่มต้นลงเรือตกปลาทะเลครั้งแรกมักสร้างความกังวลใจให้กับมือใหม่ ทั้งเรื่องอุปกรณ์ที่ซับซ้อน แรงลม คลื่นทะเล และสายตาของเพื่อนร่วมเรือ แต่เท็นยะมาดาอิคือเกมที่ทลายอุปสรรคเหล่านั้นทั้งหมด ด้วยเหตุผลสำคัญ 4 ประการ:

1. **อุปกรณ์น้ำหนักเบา คล่องตัวสูง:** คุณไม่ต้องถือคันเบ็ดหนักอึ้ง หรือแบกรอกเบทแคสติ้งตัวโตและแบตเตอรี่รอกไฟฟ้า คันสปินนิ่งขนาดเบาช่วยให้นักตกปลาทุกเพศทุกวัยยืนถือตกปลาได้ทั้งวันโดยไม่ล้าแขน
2. **ขั้นตอนพื้นฐานเรียบง่าย:** หัวใจของเกมมีเพียง 3 สเต็ป: **หย่อนถึงพื้น $\rightarrow$ ยกกระดก $\rightarrow$ ปล่อยร่อน** ไม่ต้องตีสายทำระยะไกล แค่ปล่อยสายลงไปตามแนวดิ่งข้างกราบเรือ
3. **อ่านระดับความลึกได้ด้วยตาเปล่า:** ด้วยสาย PE แบบมัลติคัลเลอร์ (Multicolor Line) ที่เปลี่ยนสีทุก ๆ 10 เมตร นักตกปลาสามารถนับความลึกและรู้ได้ทันทีว่าเหยื่ออยู่ที่กี่เมตรจากผิวน้ำ
4. **โอกาสพบปลาหลากหลายชนิด (High Hit Rate):** กุ้งสดที่ร่อนลงอย่างเป็นธรรมชาติหน้าดิน ไม่เพียงดึงดูดปลามาดาอิเท่านั้น แต่ยังเป็นอาหารอันโอชะของปลาหน้าดินชั้นยอดชนิดอื่น ๆ ทำให้แทบไม่มีช่วงเวลาที่น่าเบื่อหน่ายบนเรือ

## 3. คันเบ็ด 2.4 เมตร: ปรัชญา "ปลายอ่อนนุ่ม โคนเหนียวแน่น" (Soft Tip, Stiff Butt)

คันเบ็ดที่ใช้ในเกมเท็นยะมาดาอิ มีการออกแบบเฉพาะทางที่แตกต่างจากคันตกปลาชายฝั่งหรือคันจิ๊กกิ้งทั่วไปอย่างสิ้นเชิง:

```
[โครงสร้างคันเท็นยะมาดาอิ ความยาว ~2.4 เมตร]
┌──────────────────────────────────────┬─────────────────────────┐
│        ช่วงปลายคัน (Tip Action)      │   ช่วงโคนคัน (Butt Power) │
│   นุ่ม ไว สัมผัสสูง (Solid/Mega Top)   │   เหนียว แกร่ง ส่งแรงวัดแน่น  │
└──────────────────────────────────────┴─────────────────────────┘
```

- **ความยาวมาตรฐาน 2.4 เมตร (ประมาณ 7 ฟุต 10 นิ้ว ถึง 8 ฟุต):** เป็นความยาวที่ลงตัวที่สุดสำหรับเรือตกปลาญี่ปุ่น ช่วยให้กวาดสายข้ามแนวกราบเรือได้สะดวก พยุงเหยื่อให้อยู่ในแนวดิ่ง และช่วยซับแรงกระเพื่อมของคลื่นเรือได้อย่างนุ่มนวล
- **แอ็กชันแบบ 7:3 หรือ 8:2 (Choushi):**
  - **ปลายคันอ่อนนุ่มเป็นพิเศษ (Solid Tip / Mega Top):** ปลายคันที่ให้ตัวได้ดีช่วยให้เหยื่อกุ้งร่อนตัวลงได้อย่างเป็นธรรมชาติ และเมื่อปลามาดาอิเข้ามาดูดกินเหยื่อ ปลายคันจะโค้งตามโดยไม่สร้างแรงต้าน ทำให้ปลาไม่รู้สึกระแวงและไม่คายเหยื่อทิ้ง
  - **โคนคันทรงพลัง (Strong Butt):** ปากของปลามาดาอิเต็มไปด้วยฟันหน้าทรงฟันแทะและแผ่นกระดูกแข็งดั่งหิน หากโคนคันนิ่มเกินไป แรงวัดเบ็ดจะไม่สามารถส่งไปตอกคมเบ็ดให้ทะลุกระดูกขากรรไกรได้ คันเท็นยะที่ดีจึงต้องมีโคนคันที่แข็งแรงพอที่จะตวัดเซ็ตฮุคได้อย่างเด็ดขาด
- **ระดับพาวเวอร์ที่แนะนำ:** สำหรับมือใหม่ คันเวท **MH (Medium Heavy)** คือตัวเลือกที่ครอบคลุมที่สุด เพราะสามารถรองรับหัวเท็นยะได้ตั้งแต่น้ำหนักเบา (เบอร์ 2) ไปจนถึงน้ำหนักปานกลาง-หนัก (เบอร์ 10–12) ในวันน้ำเชี่ยว

![คันเท็นยะมาดาอิความยาว 2.4 เมตร](assets/tenya-rod.jpg)

**ภาพที่ 2:** คันเท็นยะมาดาอิเฉพาะทางความยาว 2.4 เมตร ที่มีปลายคันไวสัมผัสและโคนคันทรงพลังสำหรับสู้ปลาหน้าดิน

## 4. รอกสปินนิ่งเบอร์ 2500 กับสาย PE 0.8: สมดุลแห่งการรับรู้และการผ่อนแรง

ระบบขับเคลื่อนของเกมเท็นยะมาดาอิต้องอาศัยความกะทัดรัดและการทำงานของระบบเบรกที่ไว้ใจได้:

- **รอกสปินนิ่งขนาดเบอร์ 2500 (หรือ LT 2500 ของ DAIWA):**
  - เป็นขนาดที่บาลานซ์น้ำหนักกับคัน 2.4 เมตรได้พอดีที่สุด สปูลมีความจุสาย **PE 0.8 ได้ประมาณ 200 เมตร** ซึ่งเพียงพอสำหรับระดับน้ำลึก 20–60 เมตร และยังมีสายสำรองเผื่อกรณีปลาลากสายยาว
  - อัตราทดรอบ: นิยมใช้รอบมาตรฐาน (Normal Gear) หรือรอบสูงปานกลาง (XH) เพื่อให้เก็บสายที่หย่อนได้รวดเร็ว
  - **ระบบเบรกอัตโนมัติ (ATD - Automatic Tournament Drag):** สำคัญที่สุดในการสู้ปลามาดาอิ เพราะปากปลาฉีกขาดง่ายและสายหลักมีขนาดเล็กเพียง PE 0.8 เบรกต้องจ่ายสายได้อย่างนุ่มนวลตั้งแต่เสี้ยววินาทีแรกที่ปลาพุ่งกระชาก โดยไม่มีอาการสะดุด
- **สายหลัก PE 0.8 (แบบสลับสีทุก 10 เมตร):**
  - สาย PE ขนาดเล็กเพียง 0.8 ช่วยตัดกระแสน้ำได้เฉียบคม ลดอาการสายโค้งป่องตามน้ำ (Line Belly) ทำให้เหยื่อดิ่งตรงลงสู่พื้นและส่งสัมผัสการกัดขึ้นมาถึงมือได้อย่างชัดเจน
- **ช็อคลีดเดอร์ฟลูออโรคาร์บอน เบอร์ 2.5–3 (ประมาณ 10–12 ปอนด์):**
  - ความยาวประมาณ **3 ถึง 5 เมตร** ฟลูออโรคาร์บอนช่วยป้องกันการขูดขีดกับเปลือกหอย แนวปะการัง และกราบเรือ พร้อมทั้งให้ความโปร่งใสในน้ำทะเลลึก

![รอกสปินนิ่ง 2500 ที่จุ PE 0.8 ได้ 200 เมตร](assets/tenya-reel.jpg)

**ภาพที่ 3:** รอกสปินนิ่งขนาด 2500 ประกบสาย PE 0.8 สลับสี เพื่อการอ่านความลึกที่แม่นยำและการควบคุมที่คล่องตัว

## 5. ถอดรหัสหัวเท็นยะ 3 รูปแบบ และสูตรคำนวณน้ำหนักตามความลึก

บนโต๊ะอุปกรณ์ มิยาซาวะหยิบหัวเท็นยะรูปทรงต่าง ๆ ขึ้นมาจำแนกให้เห็นถึงข้อดีและสถานการณ์การใช้งานของแต่ละประเภท:

```
[ประเภทของหัวเท็นยะ]
1. แบบฟิกซ์ (固定型 - Kotei-gata)   ---> ทรงพีระมิด/เหลี่ยม ร่อนช้าแบบฮิระฮิระ คลื่นน้ำดี มาตรฐาน Ohara
2. แบบคาบูระ (カブラ - Kabura)       ---> ทรงกลม/กระสุน ดิ่งตรงเร็ว ตัดกระแสน้ำเชี่ยว ลงหน้าดินไว
3. แบบไกด์อิสระ (誘導型 - Yudou Type) ---> หัวตะกั่วสไลด์แยกกับเบ็ด ปลาดูดกลืนไร้แรงต้าน ปลดปลาสะบัดหลุดยาก
```

1. **แบบฟิกซ์ / หัวเหลี่ยมดั้งเดิม (固定型 - Kotei-gata):**
   - หัวตะกั่วทรงสามเหลี่ยมหรือพีระมิดตัด ด้านล่างแบน ตะขอหลักฝังติดแน่นกับหัว
   - **จุดเด่น:** เมื่อจมน้ำจะร่อนส่ายไปมาเหมือนใบไม้ร่วง เรียกว่า **"ฮิระฮิระ ฟอล" (ひらひらフォール)** ดึงดูดสายตาปลามาดาอิที่มองขึ้นมาจากพื้นได้นานที่สุด เป็นรูปทรงยอดนิยมตลอดกาล
2. **แบบคาบูระ (カブラ - Kabura):**
   - หัวทรงกลมมนหรือทรงหยดน้ำที่มีจุดศูนย์ถ่วงทิ้งตัวลงด้านล่าง
   - **จุดเด่น:** จมดิ่งลงสู่หน้าดินอย่างรวดเร็วเป็นเส้นตรง เหมาะสำหรับวันที่กระแสน้ำไหลแรงจัด หรือต้องการส่งเหยื่อฝ่าฝูงปลาเล็กผิวน้ำลงสู่หน้าดินให้เร็วที่สุด
3. **แบบไกด์ / สายสไลด์อิสระ (誘導タイプ - Yudou Type):**
   - หัวตะกั่วเจาะรูร้อยสาย โดยชุดตัวเบ็ดจะผูกติดกับสายลีดเดอร์และเลื่อนตัวได้อย่างอิสระ (คล้ายกลไกของเหยื่อไทรับเบอร์)
   - **จุดเด่น:** เมื่อปลามาดาอิเข้าดูดกุ้ง จะไม่มีน้ำหนักของหัวตะกั่วมาหน่วงรั้ง ทำให้ปลากลืนเหยื่อได้ลึก และในขณะสู้ปลา หัวตะกั่วจะเลื่อนถอยออกไป ลดแรงเหวี่ยงที่ปลาจะสะบัดเบ็ดหลุด

### กฎการเลือกน้ำหนักเท็นยะตามระดับความลึก
ในวงการตกปลาญี่ปุ่น น้ำหนักของเท็นยะจะเรียกเป็นหน่วย **"โกะ" (号 - Gou)** โดยที่ **1 โกะ มีน้ำหนักประมาณ 3.75 กรัม**:

| ระดับความลึกของหมาย | ขนาดเท็นยะมาตรฐาน | น้ำหนักกรัมโดยประมาณ | สภาพกระแสน้ำ |
|---|---|---|---|
| **น้ำตื้น 10–15 เมตร** | เบอร์ 2 – 3 | 7.5 – 11.25 กรัม | น้ำนิ่ง คลื่นลมสงบ |
| **น้ำลึกปานกลาง 20–25 เมตร** | เบอร์ 4 – 5 | 15.0 – 18.75 กรัม | สภาพหมายมาตรฐานทั่วไป |
| **น้ำลึก 30–40 เมตร** | เบอร์ 6 – 8 | 22.5 – 30.0 กรัม | น้ำไหลปานกลาง ลมพัดเรือไหล |
| **น้ำลึก 40–60 เมตร หรือน้ำเชี่ยว** | เบอร์ 10 – 15 | 37.5 – 56.25 กรัม | กระแสน้ำไหลแรง ต้องใช้หัวจมเร็ว |

> **สูตรจำง่าย ๆ ของมิยาซาวะ:** นำความลึกเป็นเมตรหารด้วย 5 เช่น ลึก 20 เมตร ให้เริ่มที่เบอร์ 4 (15 กรัม), ลึก 30 เมตร ให้เริ่มที่เบอร์ 6 (22.5 กรัม) แต่หากมีลมพัดเรือไหลเร็ว ให้เพิ่มขนาดขึ้นอีก 1–2 เบอร์ เพื่อให้สายตั้งฉากกับผิวน้ำได้มากที่สุด

![เท็นยะแบบต่าง ๆ ที่มิยาซาวะถืออยู่](assets/tenya-close.jpg)

**ภาพที่ 4:** หัวเท็นยะแบบฟิกซ์ คาบูระ และแบบไกด์ หลากสีสันและน้ำหนัก ที่มิยาซาวะเตรียมไว้ปรับตามสภาพกระแสน้ำ

## 6. ศิลปะการเกี่ยวกุ้ง: ความตรงและสมดุลคือหัวใจของแอ็กชัน

เหยื่อที่ใช้ในเกมเท็นยะคือกุ้งทะเลสดหรือกุ้งแช่แข็งเกรดพิเศษ เท็นยะประกอบด้วยตัวเบ็ด 2 ตัว ได้แก่:
- **โอยะบาริ (親針 - Oyabari):** ตะขอหลักขนาดใหญ่ที่ติดอยู่กับหัวเท็นยะ ทำหน้าที่ยึดโครงสร้างตัวกุ้งและรับแรงสู้ปลา
- **มาโกบาริ (孫針 - Magobari):** ตะขอรองหรือเบ็ดช่วยตัวเล็กที่ผูกโยงด้วยสายเคฟลาร์ ทำหน้าที่เกี่ยวล็อกส่วนหัวของกุ้ง

```
[ขั้นตอนการเกี่ยวกุ้งให้ตรงสมบูรณ์แบบ]
1. ใช้กรรไกรเล็มตัดแพนหางกุ้งออก เพื่อเปิดช่องให้ตัวเบ็ดสอดเข้าแกนกลาง
2. ฝังเบ็ดหลัก (โอยะบาริ) เข้าที่รอยตัดหาง สอดทะลุแกนกลางลำตัวให้ออกมาทางใต้ท้อง
3. เลื่อนลำตัวกุ้งขึ้นไปชิดหัวตะกั่ว จัดลำตัวให้ "เหยียดตรงเป็นแนวเดียวกับตัวเบ็ด"
4. กดตัวล็อกกุ้ง (エビロック - Ebi Lock) เพื่อตรึงไม่ให้กุ้งรูดหลุด
5. นำเบ็ดรอง (มาโกบาริ) ปักเบา ๆ เข้าที่แผ่นเปลือกหลังส่วนอกหรือช่วงหัวระหว่างตากุ้ง
```

มิยาซาวะย้ำอย่างหนักแน่นว่า **"ห้ามเกี่ยวกุ้งจนลำตัวโค้งงอเด็ดขาด"** เพราะเมื่อกุ้งที่โค้งงอตกลงสู่กระแสน้ำใต้น้ำ มันจะหมุนควงสว่านเหมือนใบพัดเรือ ซึ่งทำให้สายเบ็ดบิดเป็นเกลียว และปลามาดาอิที่สายตาเฉียบคมจะตกใจหนีทันที นอกจากนี้ หากเหยื่อกุ้งถูกปลาเล็กแทะจนหัวขาดหรือเละ ต้องเปลี่ยนกุ้งตัวใหม่ทันที อย่าเสียดายกุ้ง เพราะปลามาดาอิจะไม่แตะต้องเหยื่อที่เสียรูปทรง

![มือกำลังเกี่ยวกุ้งเข้ากับเท็นยะ](assets/tenya-bait.jpg)

**ภาพที่ 5:** การเกี่ยวกุ้งสดเข้ากับหัวเท็นยะอย่างประณีต จัดลำตัวเหยียดตรง พร้อมล็อกด้วยเข็ม Ebi Lock เพื่อป้องกันเหยื่อหลุด

## 7. เงื่อนผูกสายเฉพาะกิจ: No-Name Knot และ Double Clinch Knot

ความมั่นใจในการตกปลาทะเลเริ่มต้นจากความแข็งแกร่งของเงื่อนผูกสาย มิยาซาวะสาธิตการผูกปมสำคัญ 2 เงื่อน:

1. **ปมโนเนม (No-Name Knot):** สำหรับต่อระหว่าง **สายหลัก PE 0.8 กับช็อคลีดเดอร์ฟลูออโรคาร์บอน**
   - พับสาย PE ทบสองชั้นเป็นห่วงยาว แล้วนำปลายสายลีดเดอร์สอดผ่านห่วง
   - พันปลายสาย PE รอบแกนสายลีดเดอร์ขึ้นไป 10–11 รอบ แล้วพันย้อนกลับลงมาอีก 10–11 รอบ
   - สอดปลายสายกลับเข้าห่วงเดิมในทิศทางตรงกันข้าม ชโลมน้ำลายหรือน้ำเพื่อลดความร้อนจากการเสียดสี แล้วรูดสายทั้งสองฝั่งให้เงื่อนกระชับแน่น
2. **ปมดับเบิลคลินช์ (Double Clinch Knot):** สำหรับผูก **ปลายสายลีดเดอร์เข้ากับห่วงหัวเท็นยะ**
   - สอดสายลีดเดอร์ผ่านห่วงตาเบ็ดของเท็นยะ 2 รอบ เพื่อสร้างห่วงคู่รับแรงเสียดสี
   - พันปลายสายรอบสายหลัก 5 รอบ แล้วสอดปลายย้อนกลับเข้าห่วงคู่ ชโลมน้ำแล้วดึงรูดให้แน่น ตัดปลายสายเหลือไว้ประมาณ 3–5 มม.

## 8. กลยุทธ์การหย่อนเหยื่อและการอ่านระดับความลึกจากสีสาย

เมื่อเรือเข้าสู่พิกัดหมาย มิยาซาวะเตรียมหย่อนเหยื่อลงน้ำด้วยท่าทางที่เปี่ยมไปด้วยสมาธิ:

- **การคอนโทรลสายด้วยปลายนิ้ว (Feathering):** เปิดหน้ารอกสปินนิ่ง ใช้นิ้วชี้หรือนิ้วโป้งแตะแตะขอบสปูลเบา ๆ เพื่อชะลอไม่ให้สายฟู่ไหลออกเร็วเกินไป ปล่อยให้หัวเท็นยะดึงกุ้งดิ่งลงอย่างสม่ำเสมอ
- **การอ่านความลึกจากสีสาย PE:**
  - สังเกตสีของสายที่ไหลผ่านไกด์ท็อป: ทุก ๆ 10 เมตร สายจะเปลี่ยนเป็นสีใหม่ (เช่น น้ำเงิน $\rightarrow$ ส้ม $\rightarrow$ เขียว $\rightarrow$ ชมพู $\rightarrow$ เหลือง) และมีขีดคั่นทุก 1 เมตร
  - หากกัปตันเรือประกาศว่า "ความลึก 35 เมตร" ให้นับสายเปลี่ยนสีไป 3 ช่วงเต็ม (30 เมตร) แล้วเตรียมรับสัมผัสในอีก 5 เมตรที่เหลือ
- **สัญญาณเมื่อเหยื่อแตะถึงพื้น (Chakutei - 着底):**
  1. สาย PE ที่กำลังไหลออกจากสปูลอย่างรวดเร็วจะหยุดกึกลงทันที
  2. สายเบ็ดระหว่างปลายคันกับผิวน้ำจะหย่อนตัวลง (Slack line)
  3. ปลายคันเบ็ดที่โค้งงอจากน้ำหนักหัวเท็นยะจะดีดตัวกลับคืนสู่แนวตรง
  - **การปฏิบัติทันที:** ปิดหน้ารอกอย่างรวดเร็ว หมุนเก็บสายที่หย่อนให้ตึงพอดี แล้วยกปลายคันขึ้นตั้งฉากเตรียมพร้อม ห้ามปล่อยให้หัวเท็นยะนอนนิ่งแช่บนพื้นดินนานเกินไป เพราะจะติดหินหรือถูกปลาปักเป้าแทะเหยื่อหมด

![มิยาซาวะหย่อนเท็นยะจากเรือ](assets/tenya-cast.jpg)

**ภาพที่ 6:** การหย่อนเท็นยะจากกราบเรือ โดยใช้นิ้วคอยแตะชะลอสายและสายตาจับจ้องที่สีของสาย PE เพื่ออ่านความลึก

## 9. จังหวะยก–ปล่อย (Lift & Fall) และสุดยอดเคล็ดลับ "Maki-otoshi"

เมื่อเหยื่อถึงพื้นดิน การสร้างแอ็กชันที่ถูกต้องคือสิ่งที่จะชี้ขาดผลแพ้ชนะ:

1. **จังหวะยก (Lift / Shakuri):**
   - ยกปลายคันเบ็ดขึ้นอย่างนุ่มนวลแต่มั่นคง จากระดับระนาบน้ำขึ้นสู่มุมประมาณ 10–11 นาฬิกา (ระยะยกเหยื่อลอยขึ้นจากพื้นประมาณ 1 ถึง 1.5 เมตร)
   - การยกนี้เปรียบเสมือนการสั่งให้กุ้งดีดตัวหนีขึ้นมาจากพื้นทราย ปลุกเร้าสายตาของปลามาดาอิในบริเวณนั้น
2. **จังหวะปล่อยร่อน (Tension Fall):**
   - ค่อย ๆ ผ่อนปลายคันเบ็ดตามเหยื่อลงมาอย่างช้า ๆ รักษาสายเบ็ดให้ตึงพอดีรับความรู้สึกได้ตลอดเวลา
   - ปล่อยให้หัวเท็นยะพากุ้งร่อนส่ายลงมาสู่พื้นอย่างแผ่วเบา **มากกว่า 80% ของปลามาดาอิจะเข้าชาร์จเหยื่อในเสี้ยววินาทีนี้!**
3. **การหมุนเก็บแล้วหย่อนใหม่ (巻き落とし - Maki-otoshi):**
   - หากคุณทำจังหวะ ยก $\rightarrow$ ปล่อยร่อน ซ้ำ ๆ อยู่กับที่ประมาณ 4–6 รอบแล้วยังไม่มีปลาแตะต้อง **อย่าแช่เหยื่อไว้ที่เดิม**
   - ให้หมุนรอกเก็บสายขึ้นมาอย่างรวดเร็วประมาณ **10 ถึง 15 เมตร** หยุดนิ่งดูเชิง 2–3 วินาที จากนั้นจึงเปิดหน้ารอกปล่อยให้เหยื่อจมดิ่งลงสู่พื้นใหม่อีกครั้ง
   - **ทำไมต้องทำ Maki-otoshi?** เพราะการตกบนเรือที่ลอยตามลม สายเบ็ดจะเริ่มเอียงเฉียงออกไปเรื่อย ๆ ทำให้มุมการยกเหยื่อผิดเพี้ยน การเก็บสายขึ้นแล้วปล่อยใหม่จะช่วยรีเซ็ตให้สายกลับมาตั้งฉากในแนวดิ่ง อีกทั้งยังเป็นการจำลองสถานการณ์เหมือนมีกุ้งตัวใหม่ร่วงหล่นลงมาจากฟ้า ซึ่งจะกระตุ้นสัญชาตญาณความอยากรู้อยากเห็นของปลาใหญ่ที่คุมเชิงอยู่ให้ตัดสินใจเข้ากัดทันที

![มิยาซาวะยกคันขึ้นแรง ๆ หนึ่งครั้งก่อนปล่อยให้เท็นยะจม](assets/tenya-lift.jpg)

**ภาพที่ 7:** จังหวะยกคันเบ็ดขึ้นหนึ่งครั้งอย่างมีสมาธิ เพื่อให้กุ้งดีดตัวขึ้นจากพื้น แล้วค่อย ๆ ผ่อนคันรอรับจังหวะกัดตอนเหยื่อร่อนลง

## 10. การอ่านจังหวะกัด การเซ็ตฮุค และการสู้ปลามาดาอิ

สัมผัสเมื่อปลามาดาอิเข้าชาร์จเหยื่อเท็นยะ มีเอกลักษณ์เฉพาะตัวที่นักตกปลาทุกคนหลงใหล:

- **รูปแบบสัญญาณกัด:**
  - **จังหวะดูดกลืน:** ปลายคันจะกระตุกสั้น ๆ ดัง *"กึก... กึก..."* ตามด้วยปลายคันที่ถูกกดวูบลงอย่างหนักแน่น
  - **จังหวะสายหย่อน (Bite on the Slack):** ในขณะที่เหยื่อกำลังร่อนลง สายเบ็ดที่ควรจะตึงกลับหยุดนิ่งหรือหย่อนตัวกะทันหัน แสดงว่าปลามาดาอิพุ่งขึ้นมารับกุ้งเข้าปากแล้วว่ายขึ้นด้านบน
- **การวัดเบ็ด (Awase):**
  - เมื่อสัมผัสได้ถึงแรงกดที่หนักแน่น ให้ **กวาดคันเบ็ดขึ้นในแนวดิ่งอย่างยาวและมั่นคง (Full Stroke Sweep)** โดยไม่ต้องกระตุกกระชากแขนสั้น ๆ แรงสปริงของโคนคัน 2.4 เมตร จะส่งกำลังผ่านสาย PE ดันให้คมเบ็ดหลักทะลุเข้ามุมปากของปลาได้อย่างสมบูรณ์
- **การต่อสู้กับปลามาดาอิ (Fighting Technique):**
  - ปลามาดาอิมีพฤติกรรมการต่อสู้ที่เป็นเอกลักษณ์ที่เรียกว่า **"ซันดันบิกิ" (三段引き - Sandan-biki)** คือการสะบัดหัวลงกระแทกเป็นจังหวะหนัก ๆ 3 ระลอกติดต่อกัน
  - **ข้อห้ามเด็ดขาด:** ห้ามใช้แรงแขนฝืนงัดดึงสายอย่างรุนแรง เพราะขากรรไกรและริมฝีปากของปลาอาจฉีกขาด และสาย PE 0.8 อาจขาดจากแรงกระชาก ปล่อยให้ระบบเบรก ATD ส่งเสียงร้องระบายสายออกไปอย่างราบเรียบ
  - เมื่อปลาหยุดพุ่ง ให้ใช้แรงงัดของคันเบ็ดค่อย ๆ ประคองปลาลอยขึ้นมาในแนวดิ่ง หมุนเก็บสายอย่างสม่ำเสมอ
- **การนำปลาขึ้นเรือ (Landing):**
  - เมื่อปลาลอยขึ้นมาใกล้ผิวน้ำข้างกราบเรือ ให้ตะโกนบอกลูกเรือหรือกัปตันว่า "ทาโมะ!" (สวิง) แล้วประคองให้หัวปลาลอยอยู่เหนือน้ำ ลากปลาเข้าสู่ปากสวิงอย่างนุ่มนวล ห้ามยกคันดึงปลาลอยพ้นน้ำโดยไม่มีสวิงรองรับ

![ปลาไทที่ได้จากเท็นยะในคลิป](assets/tenya-fish.jpg)

**ภาพที่ 8:** ปลามาดาอิสีชมพูประกายเงินตัวสวยที่กัดเหยื่อเท็นยะอย่างแม่นยำ จากการวัดเบ็ดด้วยช่วงชักคันยาว

## 11. ปลาพลอยรสเลิศ และมารยาทสากลบนเรือตกปลา

เสน่ห์ที่น่าประทับใจอีกด้านหนึ่งของเกมเท็นยะ คือการที่คุณไม่มีทางรู้เลยว่าสิ่งมีชีวิตใต้ทะเลลึกชนิดใดจะพุ่งเข้ามากินกุ้งสดตัวนี้:

- **ปลาพลอยที่พบในทริป (Gedou):**
  - **เรนโกะได (レンコダイ - Yellowback Seabream):** ปลาตระกูลปลาไทขนาดกะทัดรัด สีชมพูอมเหลือง รสชาติหวานมัน
  - **อิโตโยริได (イトヨリダイ - Golden Threadfin Bream):** ปลาทรายแดงญี่ปุ่น ลำตัวเรียวยาวมีลายเส้นสีทองพาดผ่าน เนื้อขาวละเอียดและมีราคาสูงในตลาดปลา
  - **คาซาโกะ (カサゴ - Marbled Rockfish) และปลาเก๋าถ่าน:** ปลาหน้าดินตามกองหิน เนื้อแน่น รสชาติเข้มข้น

![มิยาซาวะกับปลาไทตัวใหญ่ที่ได้ตอนท้ายทริป](assets/tenya-big-fish.jpg)

**ภาพที่ 9:** ปลามาดาอิโทรฟี่ตัวใหญ่ช่วงท้ายทริป ที่ยอมเปิดปากกัดเหยื่อหลังจากการทำ Maki-otoshi รีเซ็ตสายอย่างต่อเนื่อง

### มารยาทสำคัญบนเรือตกปลา (Boat Etiquette)
1. **การรักษาความสะอาดบนดาดฟ้าเรือ:** เศษเปลือกกุ้ง น้ำเมือก หรือเศษสายเบ็ดที่ร่วงหล่นบนพื้นเรือ ต้องใช้น้ำทะเลล้างทำความสะอาดทันที เพื่อป้องกันไม่ให้คนอื่นเหยียบลื่นล้ม
2. **การปฏิบัติตามคำสั่งของกัปตัน:** เมื่อกัปตันประกาศ "เก็บสาย" ให้รีบหมุนสายขึ้นทันที เพื่อเตรียมย้ายพิกัดเรือ และห้ามหย่อนเหยื่อจนกว่ากัปตันจะให้สัญญาณ
3. **การสวมใส่อุปกรณ์ความปลอดภัย:** ต้องสวมใส่เสื้อชูชีพที่ได้มาตรฐานตลอดเวลาที่อยู่บนเรือ และสวมแว่นตากันแดดโพลาไรซ์เพื่อปกป้องดวงตาจากรังสี UV และตัวเบ็ดที่อาจดีดขึ้นมา

![การเก็บกวาดเรือหลังเลิกตก](assets/tenya-closing.jpg)

**ภาพที่ 10:** การทำความสะอาดดาดฟ้าเรือและจัดเก็บอุปกรณ์อย่างเป็นระเบียบหลังจบวันตกปลา แสดงถึงจิตวิญญาณของนักตกปลาที่ดี

## 12. บทสรุปและการปรับใช้กับเกมตกปลาทะเลในประเทศไทย

บทเรียนจากมิยาซาวะ ยูกิโนริ ได้พิสูจน์ให้เห็นแล้วว่า เท็นยะมาดาอิไม่ใช่เรื่องไกลตัวหรือซับซ้อนเกินเอื้อม มันคือเกมที่ผสมผสานความเรียบง่ายเข้ากับความประณีตในรายละเอียด:

```
[หัวใจ 5 ประการของเท็นยะมาดาอิ]
1. คันเบ็ด 2.4 เมตร: ปลายไวสัมผัสเพื่อการร่อนเหยื่อ โคนแข็งแรงเพื่อการเซ็ตฮุค
2. สาย PE 0.8: ตัดกระแสน้ำเฉียบคม สลับสีเพื่อการอ่านระดับความลึกที่แม่นยำ
3. หัวเท็นยะที่สมดุล: หนักพอที่จะถึงก้น แต่เบาพอที่จะร่อนตัวได้อย่างเป็นธรรมชาติ
4. กุ้งสดที่เหยียดตรง: เหยื่อต้องไม่หมุนควงสว่านในน้ำเด็ดขาด
5. เทคนิค Maki-otoshi: หมุนเก็บสายขึ้น 10-15 เมตรแล้วหย่อนใหม่ เพื่อรีเซ็ตมุมสายและกระตุ้นปลาใหญ่
```

### การนำมาประยุกต์ใช้กับทะเลไทย (อ่าวไทยและอันดามัน)
- **ปลาเป้าหมายในไทย:** ปลากะพงแดงเขี้ยว, ปลากะพงขาวธรรมชาติ, ปลากะพงทอง (อังเกย), ปลาเก๋าหน้าดิน, ปลาหัวเสี้ยม, ปลากระมง
- **การปรับอุปกรณ์:** ทะเลไทยบางหมายมีกระแสน้ำขึ้น-ลงไหลเชี่ยว อาจขยับไปใช้หัวเท็นยะน้ำหนัก **เบอร์ 8 ถึง 15 (30–56 กรัม)** และเลือกใช้ **เท็นยะแบบไกด์อิสระ (Yudou Type)** เพื่อลดการต้านน้ำ
- **สายเบ็ด:** ปรับเพิ่มเป็นสาย PE 1.0–1.2 และช็อคลีดเดอร์ 16–20 ปอนด์ หากตกในหมายกองหินปะการังหรือซากเรือจมที่มีปลาเก๋าไซส์ใหญ่

## 13. ตารางสรุปสเปกอุปกรณ์จากคลิป

| ชนิดอุปกรณ์ | รุ่นและสเปกที่มิยาซาวะแนะนำ | หน้าที่และการทำงาน |
|---|---|---|
| **คันเบ็ด (Rod)** | คันเท็นยะมาดาอิเฉพาะทาง ยาว 2.4 ม. เวท MH (แอ็กชัน 7:3 หรือ 8:2) | ปลายโซลิดซับคลื่นและส่งเหยื่อร่อน โคนเหนียวเซ็ตฮุคทะลุปากปลา |
| **รอก (Reel)** | รอกสปินนิ่งขนาด 2500 (DAIWA LT 2500) พร้อมระบบเบรก ATD | น้ำหนักเบา บาลานซ์คันดี เบรกจ่ายสายนุ่มนวลไม่กระชาก |
| **สายหลัก (Main Line)** | สายถัก PE 0.8 มัลติคัลเลอร์ (เปลี่ยนสีทุก 10 ม.) ยาว 200 ม. | ตัดน้ำได้ดีเยี่ยม ไม่ต้านกระแสน้ำ อ่านความลึกได้อย่างแม่นยำ |
| **ช็อคลีดเดอร์ (Leader)** | ฟลูออโรคาร์บอน เบอร์ 2.5–3 (10–12 ปอนด์) ยาว 3–5 เมตร | ทนทานต่อการขูดขีด ซับแรงกระชาก และพรางสายในน้ำใส |
| **หัวเท็นยะ (Tenya)** | เบอร์ 2–6 (7.5–22.5 กรัม) มีทั้งแบบฟิกซ์ คาบูระ และแบบไกด์ | เลือกน้ำหนักให้แตะก้นได้พอดีโดยไม่หนักเกินไป |
| **เหยื่อ (Bait)** | กุ้งทะเลสด พร้อมเข็มล็อกกุ้ง (Ebi Lock) | อาหารธรรมชาติที่สมบูรณ์แบบ ต้องเกี่ยวให้ลำตัวเหยียดตรงเสมอ |

## 14. พจนานุกรมคำศัพท์ตกปลาญี่ปุ่นในคลิป

| คำศัพท์ญี่ปุ่น | คำอ่านโรมาจิ | ความหมายในวงการตกปลา |
|---|---|---|
| **テンヤ** | Tenya | หัวตะกั่วถ่วงน้ำหนักที่มีตัวเบ็ดหลักในตัว ใช้เกี่ยวกุ้งสด |
| **マダイ** | Madai | ปลากะพงแดงญี่ปุ่น (Pagrus major) ราชาแห่งปลาทะเล |
| **船釣り** | Funazuri | การตกปลาจากเรือ |
| **着底** | Chakutei | จังหวะที่เหยื่อหรือหัวตะกั่วแตะถึงพื้นทะเลหน้าดิน |
| **巻き落とし** | Maki-otoshi | การหมุนเก็บสายขึ้นมา 10–15 เมตร แล้วปล่อยเหยื่อจมลงไปใหม่เพื่อรีเซ็ตสาย |
| **親針** | Oyabari | ตัวเบ็ดหลักขนาดใหญ่ที่ติดอยู่กับหัวเท็นยะ |
| **孫針** | Magobari | ตัวเบ็ดรองหรือเบ็ดช่วยตัวเล็กที่ผูกโยงด้วยสายเคฟลาร์สำหรับเกี่ยวหัวกุ้ง |
| **エビロック** | Ebi Lock | ระบบเข็มล็อกกุ้งบนหัวเท็นยะ ป้องกันไม่ให้เหยื่อเลื่อนหลุด |
| **固定型** | Kotei-gata | หัวเท็นยะแบบดั้งเดิมที่ตัวเบ็ดฝังติดแน่นกับหัวตะกั่ว |
| **カブラ** | Kabura | หัวเท็นยะทรงกลมหรือหยดน้ำที่เน้นการจมดิ่งลงสู่พื้นอย่างรวดเร็ว |
| **誘導タイプ** | Yudou Type | หัวเท็นยะแบบสไลด์อิสระ ตัวเบ็ดแยกออกจากหัวตะกั่ว |
| **ひらひらフォール** | Hira-hira Fall | แอ็กชันการร่อนส่ายไปมาอย่างแผ่วเบาของหัวเท็นยะขณะจมตัว |
| **三段引き** | Sandan-biki | แรงสะบัดกระแทกหัวลง 3 จังหวะอันเป็นเอกลักษณ์ของปลามาดาอิขณะสู้สาย |
| **タモ** | Tamo | สวิงด้ามยาวสำหรับช้อนปลาข้างกราบเรือ |
| **外道** | Gedou | ปลาพลอย หรือปลาสายพันธุ์อื่นที่ไม่ใช่ปลาเป้าหมายหลัก |
