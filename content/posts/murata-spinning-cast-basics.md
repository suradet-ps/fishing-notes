บนเวทีสัมมนาสีแดงสด **มุราตะ โมโตอิ (村田基 - Hajime Murata)** หรือ "จิม" ตำนานแห่งวงการตกปลาและปรมาจารย์ด้านการแคสติ้งของญี่ปุ่น ยืนถือคันสปินนิ่งอยู่ในมือด้วยท่าทางผ่อนคลาย ก่อนจะเปิดบทเรียนด้วยประโยคที่ทำเอานักตกปลาหลายคนต้องหยุดคิด:

> **"จริงๆ แล้ว รอกสปินนิ่งมีความลึกซึ้งและยากกว่าเบทคาสติ้งเสียอีก"**

ในสายตาของนักตกปลาทั่วไป รอกสปินนิ่ง (Spinning Reel) มักถูกมองว่าเป็น "อุปกรณ์สำหรับมือใหม่" เพราะใช้ง่าย ไม่ต้องคอยพะวงเรื่องสายฟู่เหมือนรอกเบทคาสติ้ง แค่เปิดหน้ารอกแล้วเหวี่ยงออกไป ใครๆ ก็ส่งเหยื่อให้ลอยไปข้างหน้าได้ แต่มุราตะแย้งว่า หากโจทย์ของคุณไม่ใช่แค่การโยนเหยื่อให้พ้นตัว แต่คือ **การส่งเหยื่อให้ลงตรงจุดเป้าหมายอย่างแม่นยำในระดับเซนติเมตร ซ้ำแล้วซ้ำเล่า โดยที่เหยื่อตกกระทบน้ำอย่างนุ่มนวลและไม่ทำให้ปลาตื่นตกใจ** รอกสปินนิ่งกลับเรียกร้องทักษะการควบคุมและความละเอียดอ่อนจากปลายนิ้วมากกว่าที่คุณคาดคิด

ความแม่นยำนั้นไม่ได้เกิดจากท่วงท่าการเหวี่ยงคันที่ดูหวือหวา แต่อยู่ที่การจัดระเบียบสรีระพื้นฐาน: การจับกริปให้ถูกร่องนิ้ว การเกี่ยวสายด้วยนิ้วชี้อย่างเป็นระบบ การใช้นิ้วชี้ทำหน้าที่เป็นระบบเบรก (Feathering) และการปล่อยให้สปริงของคันเบ็ดเป็นตัวดีดเหยื่อพุ่งออกไป คลิปความยาวกว่า 26 นาทีจากนิตยสาร *Lure Magazine* จึงเปรียบเสมือนการรื้อโครงสร้างความคิดเดิมๆ เพื่อสร้างมาตรฐานการแคสติ้งสปินนิ่งที่ถูกต้องอย่างแท้จริง

![มุราตะ โมโตอิ กับคันสปินนิ่งบนเวทีสอนคาสติ้ง](assets/murata-cast-opening.jpg)

**ภาพที่ 1:** มุราตะ โมโตอิ เปิดคลาสสอนการแคสติ้งสปินนิ่งบนเวที Lure Magazine ชี้ให้เห็นถึงความลึกซึ้งและรายละเอียดที่คนส่วนใหญ่มองข้าม

## 1. กริปสองนิ้ว (Two-Finger Grip): กฎเหล็กเพื่อความมั่นคงและการปกป้องสาย

จุดแรกที่มุราตะลงมือแก้ไขให้กับผู้เข้าอบรม คือ **ตำแหน่งการวางนิ้วบนขารอกสปินนิ่ง** ซึ่งมุราตะเน้นย้ำอย่างเด็ดขาดว่า ต้องเป็น **"กริปสองนิ้ว (Two-Finger Grip)"** เท่านั้น นั่นคือการวางขารอกไว้ตรงกลางระหว่าง **นิ้วกลางและนิ้วนาง**

```
[ จับนิ้วเดียว : One-Finger ]   --> ข้อมือไร้แรงพยุง คันแกว่งเซเมื่อเจอเหยื่อหนัก
[ จับสองนิ้ว : Two-Finger ]   --> สมดุลสมบูรณ์แบบ! ข้อมือมั่นคง นิ้วชี้เอื้อมคุมสายได้อิสระ
[ จับสามนิ้ว : Three-Finger ] --> นิ้วชน Line Roller สายขูดนิ้วเป็นรอยและเสื่อมสภาพเร็ว
```

### ทำไมต้องเป็นสองนิ้ว ไม่ใช่นิ้วเดียว และไม่ใช่สามนิ้ว?
* **หากจับนิ้วเดียว (One-finger):** นิ้วชี้จะอยู่หน้าขารอกเพียงนิ้วเดียว ทำให้จุดศูนย์ถ่วงของคันอยู่ห่างจากอุ้งมือ ข้อมือจะขาดแรงค้ำยัน ส่งผลให้คันเบ็ดหมุนส่ายไปมาขณะเหวี่ยงเหยื่อ
* **หากจับสามนิ้วหรือสี่นิ้ว (Three-finger / Four-finger):** อุ้งมือจะถูกเลื่อนขึ้นไปชิดกับตัวรอกมากเกินไป ส่งผลให้ปลายนิ้วก้อยหรือนิ้วนางเข้าไป **เบียดเสียดชนกับ "ไลน์โรลเลอร์ (Line Roller / ลูกกลิ้งเก็บสาย)"** ในจังหวะที่กว้านสายหมุนกลับ นอกจากจะทำให้หมุนสะดุดแล้ว เม็ดทรายและคราบสกปรกบนนิ้วจะไปเสียดสีกับสายเอ็นหรือสาย PE จนเกิดรอยขูดขีด สายจะเสื่อมสภาพและขาดผึงได้ง่ายเมื่อเจอแรงกระชากของปลาใหญ่
* **ความสมดุลของกริปสองนิ้ว:** การประกบขารอกด้วยนิ้วกลางและนิ้วนาง จะกระจายน้ำหนักของชุดอุปกรณ์ลงสู่อุ้งมืออย่างมั่นคงที่สุด และที่สำคัญที่สุดคือ มันเปิดพื้นที่ให้ **"นิ้วชี้"** สามารถยืดเหยียดออกไปแตะขอบสปูลเพื่อเกี่ยวสายและเบรกสายได้อย่างเป็นอิสระร้อยเปอร์เซ็นต์

![การจับรอกสปินนิ่งด้วยสองนิ้ว](assets/murata-cast-grip.jpg)

**ภาพที่ 2:** การจับรอกสปินนิ่งด้วย Two-Finger Grip ประกบขารอกระหว่างนิ้วกลางและนิ้วนาง เหลือนิ้วชี้ไว้ควบคุมสายอย่างอิสระ

### เทคนิคเกี่ยวสายด้วยนิ้วชี้: หมุนเข้าตำแหน่ง ไม่ต้องควานหาสาย
ข้อผิดพลาดประจำของมือใหม่ คือเมื่อเหยื่อตกกระทบน้ำแล้วต้องการตีไม้ถัดไป มักปล่อยมือซ้ายมาควานหาสายเอ็นเพื่อดึงไปเกี่ยวนิ้วชี้ ซึ่งมุราตะสอนว่าวิธีที่ถูกต้องและรวดเร็วคือ **การจัดระเบียบสายด้วยการหมุนรอก**:

1. รักษากริปสองนิ้วไว้ที่มือขวาอย่างมั่นคง
2. หมุนด้ามรอกให้ไลน์โรลเลอร์วิ่งขึ้นมาอยู่ตำแหน่งบนสุด (ใกล้กับนิ้วชี้)
3. ยื่นนิ้วชี้ขวาออกไปแตะสัมผัสสายเบาๆ บริเวณหน้าไลน์โรลเลอร์
4. ใช้มือซ้ายเปิดหน้ารอก (Bail Arm) ขึ้นอย่างนิ่มนวล

ด้วยวิธีนี้ สายจะพาดเข้าสู่ข้อแรกของปลายนิ้วชี้โดยอัตโนมัติ โดยที่คุณไม่ต้องละสายตาจากผิวน้ำ และไม่ต้องใช้มือซ้ายเอื้อมมาควานหาสายแม้แต่น้อย

![การเก็บสายด้วยนิ้วชี้หลังหมุนรอก](assets/murata-cast-pickup.jpg)

**ภาพที่ 3:** การนำสายเข้าสู่นิ้วชี้โดยการหมุนไลน์โรลเลอร์เข้าหาตำแหน่ง ไม่ต้องปล่อยมือมาควานหาสาย

> **ถนัดขวา ทำไมต้องหมุนรอกด้วยมือซ้าย? (Left-Hand Retrieve)**
>
> มุราตะให้คำแนะนำอย่างตรงไปตรงมาว่า สำหรับนักตกปลาที่ถนัดขวา **ควรใช้รอกสปินนิ่งแบบหมุนมือซ้าย** เสมอ เพราะมือขวาที่เป็นแขนข้างถนัดจำเป็นต้องรับหน้าที่หลักในการควบคุมคันเบ็ด สร้างแอ็กชันเหยื่อ วัดเบ็ด (Hookset) และสู้ปลา 
>
> หากใช้มือขวาหมุนรอก คุณจะต้องสลับคันจากมือขวาไปมือซ้ายทุกครั้งหลังตีเหยื่อ ซึ่งจะทำให้เสียจังหวะสำคัญในเสี้ยววินาทีที่เหยื่อตกกระทบน้ำ ซึ่งมักเป็นช่วงที่ปลาชาร์จเหยื่อทันที การฝึกใช้มือซ้ายหมุนรอกใช้เวลาปรับตัวเพียง 2-3 วันก็จะรู้สึกเป็นธรรมชาติอย่างสมบูรณ์

## 2. นิ้วชี้คือเบรกทั้งระบบ: ศาสตร์แห่งการเฟเธอร์ริ่ง (Feathering)

ความแตกต่างระหว่างนักตกปลาทั่วไปกับโปรระดับมาสเตอร์ วัดกันที่ **"การควบคุมสายหลังเหยื่อหลุดออกจากคัน"**

เนื่องจากรอกสปินนิ่งไม่มีระบบหน่วงแม่เหล็กหรือหน่วงเม็ดราคอยควบคุมรอบหมุนเหมือนรอกเบทคาสติ้ง สายจึงพร้อมที่จะพุ่งหลุดออกจากขอบสปูลตามแรงเฉื่อยของเหยื่ออย่างไร้ขีดจำกัด หากปล่อยให้สายวิ่งออกไปเองตามยถากรรม สายจะพองตัวเป็นห่วงลอยตามลม (Wind Knot) เหยื่อจะพุ่งเลยจุดเป้าหมาย และส่งเสียงดังสนั่นเมื่อตกน้ำ

มุราตะจึงนิยามว่า **"ในระบบสปินนิ่ง นิ้วชี้ของคุณคือระบบเบรกอัจฉริยะเพียงหนึ่งเดียว"** ซึ่งในภาษาสากลเรียกว่า **Feathering (หรือ サミング ในภาษาญี่ปุ่น)**

```
[ สปินนิ่งไม่มีหน่วงอัตโนมัติ ]  --> นิ้วชี้ทำหน้าที่เป็นทั้งเบรกและคันเร่ง
[ จังหวะเหยื่อลอย ]          --> ยื่นปลายนิ้วชี้แตะขอบสปูลเบาๆ ให้ขดสายวิ่งสะกิดนิ้ว
[ เหยื่อตกถึงเป้าหมาย ]       --> กดนิ้วชี้ล็อคขอบสปูลทันที ตัดสายหย่อน 100%
```

### วิธีการควบคุม Feathering อย่างละเอียด
1. **การสัมผัสแผ่วเบา:** หลังปล่อยเหยื่อพุ่งออกไป ให้เหยียดปลายนิ้วชี้ขวาไปจ่อไว้ที่บริเวณขอบหน้าของสปูล (Spool Lip) ปล่อยให้ขดสายเอ็นที่คลายตัวออกจากสปูลวิ่งกระทบกับปลายนิ้วเบาๆ
2. **ปรับระยะทางแบบเรียลไทม์:** 
   - หากสังเกตเห็นว่าเหยื่อเริ่มพุ่งแรงเกินไปและกำลังจะเลยเป้า ให้เพิ่มแรงกดปลายนิ้วลงบนขอบสปูลทีละนิด เพื่อชะลอความเร็วของเหยื่อ
   - หากเหยื่อเริ่มหมดแรงส่ง ให้ผ่อนปลายนิ้วออกเพื่อให้สายไหลได้อิสระ
3. **การล็อคสายเมื่อถึงผิวน้ำ:** ในเสี้ยววินาทีก่อนที่เหยื่อจะแตะผิวน้ำ ให้ **กดนิ้วชี้ทาบลงบนขอบสปูลสนิททันที** เพื่อหยุดการจ่ายสาย เหยื่อจะตกลงน้ำอย่างนุ่มนวล ไร้เสียงรบกวน และสายหน้าจะตึงเปรี๊ยะพร้อมสร้างแอ็กชันได้ตั้งแต่รอบแรกของการหมุน

## 3. Overhead Cast: "ถือตรง ยกตรง ตีตรง" ในระนาบ 12 นาฬิกา

เมื่อจัดกริปและเข้าใจระบบเบรกแล้ว ท่าครูพื้นฐานที่ทุกคนต้องทำให้สมบูรณ์แบบคือ **Overhead Cast (การตีข้ามศีรษะ)**

มุราตะสรุปหัวใจของท่านี้ไว้เพียง 3 คำสั้นๆ: **"ถือตรง ยกตรง ตีตรง"**

หลายคนพยายามเงื้อคันเบ็ดไปข้างหลังไกลๆ หรือวาดแขนเป็นวงกว้างเหมือนนักเทนนิส ซึ่งมักทำให้ปลายคันเบ็ดแกว่งเซและทำให้เหยื่อบินเบี่ยงออกซ้ายหรือขวา มุราตะอธิบายว่าการตี Overhead ที่ถูกต้อง คันเบ็ดและเหยื่อจะต้องเคลื่อนที่อยู่ใน **ระนาบแนวดิ่งเดียวกัน (Vertical Plane) เสมอ**

### กฎสำคัญ: เหยื่อต้องไม่แกว่งผ่านศีรษะ
* ในระหว่างที่ยกคันขึ้นไปข้างหลัง เหยื่อจะต้องทิ้งตัวเป็นแนวตรงอยู่ด้านหลังของคันเบ็ด โดย **เหยื่อจะต้องไม่แกว่งข้ามศีรษะของนักตกปลาโดยเด็ดขาด**
* ใช้ข้อมือเป็นตัวควบคุมแนวแกน ยกคันขึ้นตรงๆ ทำมุมประมาณ 12–1 นาฬิกาด้านหลัง แล้วหยุดมือเพื่อโหลดสปริงปลายคัน จากนั้นสะบัดข้อมือดีดคันเบ็ดกลับมาข้างหน้าในแนวเส้นตรงเดียวกัน
* หากจังหวะถูก เหยื่อจะพุ่งแหวกอากาศออกไปเป็นเส้นตรงเหมือนวิถีกระสุนปืน เข้าหาเป้าหมายได้อย่างแม่นยำโดยไม่มีอาการส่ายแฉลบ

## 4. Side, Backhand และ Flip Cast: พลิกแพลงทุกมุมด้วยแรงสปริงของคัน

เมื่อฝึกฝน Overhead จนสามารถตีเหยื่อได้ตรงทางแล้ว การต่อยอดไปสู่ท่าแคสต์อื่นๆ จะกลายเป็นเรื่องง่ายทันที เพราะทุกท่าต่างใช้ฟิสิกส์พื้นฐานเดียวกัน นั่นคือ **"การสะบัดคันให้เกิดแรงสปริงตัว (Rod Flex) ไม่ใช่การออกแรงดันคันไปข้างหน้า"**

### 1. Side Cast (การตีด้านข้าง)
ใช้ในสถานการณ์ที่มีกิ่งไม้หรือเพดานสะพานขวางอยู่เหนือศีรษะ หรือในวันที่ลมพัดแรงจนต้องลดวิถีเหยื่อให้ขนานกับผิวน้ำ วิธีการคือการเอียงคันเบ็ดในแนวนอน ใช้ข้อมือสะบัดคันไปด้านข้างแล้วหยุดเพื่อให้ปลายคันดีดเหยื่อพุ่งเลียดขอบตลิ่งออกไป

### 2. Backhand Cast (การตวัดหลังมือ)
ทักษะจำเป็นสำหรับการส่งเหยื่อเข้าสู่มุมอับทางด้านตรงข้ามของลำตัว (เช่น ด้านซ้ายของคนถนัดขวา) โดยไม่ต้องขยับเท้าหรือเปลี่ยนตำแหน่งยืน เพียงแค่ยกคันไขว้หน้าอก ใช้การสะบัดหลังมือเพื่อโหลดปลายคัน เหยื่อก็จะพุ่งเข้าสู่ช่องแคบได้อย่างคล่องตัว

### 3. Flip Cast (การสะบัดระยะประชิด)
ท่าไม้ตายสำหรับระยะ 5–10 เมตร เช่น การส่งเหยื่อเข้าใต้กิ่งไม้เตี้ยๆ หรือซอกหิน โดยใช้การเคาะสะบัดปลายคันลงด้านล่างสั้นๆ เพื่อให้ปลายคันดีดตัวส่งเหยื่อพุ่งออกไปอย่างเงียบเชียบ

![การตี side cast](assets/murata-cast-side.jpg)

**ภาพที่ 6:** ท่า Side Cast ที่อาศัยการสะบัดข้อมือในแนวนอนเพื่อส่งเหยื่อลอดใต้สิ่งกีดขวางเหนือศีรษะ

## 5. วิถีต่ำและการสกิปข้ามผิวน้ำ (Skipping): "มองเป้าหมาย ไม่มองผิวน้ำ"

หนึ่งในบทเรียนที่น่าทึ่งที่สุดของมุราตะ คือเทคนิคการยิงเหยื่อใน **วิถีพุ่งต่ำ (Low Trajectory)** และการทำ **Skipping (การส่งเหยื่อให้กระดอนผิวน้ำเข้าไปใต้สิ่งกีดขวาง)** เช่น ประตูน้ำ ใต้ท้องเรือ หรือชายคาตลิ่งชัน

### จิตวิทยาการมอง: มองเป้าหมาย อย่ามองผิวน้ำข้างหน้า
มุราตะชี้ให้เห็นข้อผิดพลาดเชิงจิตวิทยาของนักตกปลาส่วนใหญ่ว่า เมื่อต้องการตีเหยื่อให้กระดอนผิวน้ำ สายตามักจะจ้องมองไปที่ "จุดตกกระทบน้ำจุดแรกตรงหน้า" ซึ่งผลลัพธ์คือ สมองจะสั่งให้มือขว้างเหยื่อพุ่งปักหัวลงน้ำอย่างรุนแรงจนเหยื่อจมดิ่งและหยุดชะงัก

> **กฎเหล็กของมุราตะ:** **"จงมองไปที่ช่องเป้าหมายลึกสุดใต้สะพาน อย่ามองผิวน้ำตรงหน้าคุณ"**
>
> เมื่อสายตาของคุณจับจ้องอยู่ที่เป้าหมายปลายทาง ร่างกายจะปรับองศาการปล่อยเหยื่อและมุมคันให้ขนานกับผิวน้ำโดยอัตโนมัติ เหยื่อจะพุ่งออกจากปลายคันในระนาบราบเรียบ

### กลไกการสร้างการสกิปที่สมบูรณ์แบบ
1. ดีดเหยื่อออกไปด้วยมุมพุ่งต่ำขนานกับผิวน้ำ
2. ทันทีที่เหยื่อพุ่งออกไป ให้ยกปลายคันขึ้นเล็กน้อยเพื่อประคองสายหน้า
3. **ใช้นิ้วชี้ทำ Feathering แตะชะลอสายเบาๆ:** การแตะสายจะช่วยยกหัวเหยื่อให้เชิดขึ้นเล็กน้อย ทำให้ท้องเหยื่อตบกระทบผิวน้ำแล้วกระดอนข้ามผิวน้ำ (Skip) พุ่งลึกเข้าไปในซอกหลืบมืดได้อย่างลื่นไหล

![จุดตีวิถีต่ำบริเวณประตูน้ำ](assets/murata-cast-low.jpg)

**ภาพที่ 7:** การอ่านมุมหมายบริเวณประตูน้ำและแนวตอม่อสะพาน ซึ่งต้องอาศัยวิถีพุ่งต่ำและการ Feathering เพื่อส่งเหยื่อเข้าไปลึกที่สุด

## 6. บทพิสูจน์ภาคสนาม: ความแม่นยำคือตัวกำหนดผลลัพธ์

ในช่วงท้ายของคลิป มุราตะได้พาลงเรือเพื่อทดสอบเทคนิคทั้งหมดในสนามจริง ท่ามกลางแนวสาหร่ายและกอหญ้าที่รกทึบริมตลิ่ง

มุราตะใช้ท่า Flip และ Side Cast ส่งเหยื่อตัวเล็กลงไปเฉียดชิดขอบกอหญ้าในระยะห่างเพียงไม่กี่เซนติเมตร เหยื่อแตะผิวน้ำอย่างเงียบกริบด้วยการล็อคสายของนิ้วชี้ และในจังหวะที่เหยื่อเริ่มขยับเพียงรอบเดียว ปลาแบสตัวสวยก็พุ่งเข้าชาร์จเหยื่อเต็มปากทันที

สิ่งที่มุราตะต้องการสื่อสารกับนักตกปลาทุกคน ไม่ใช่การอวดขนาดของปลา แต่เป็นการตอกย้ำความจริงที่ว่า:
* **หากคุณตีเหยื่อไม่แม่นยำ:** ต่อให้มีเหยื่อราคาแพงที่สุดในโลก คุณก็ไม่มีวันส่งมันเข้าไปถึงปากของปลาที่กบดานอยู่ลึกได้
* **หากคุณตีแม่น แต่เหยื่อตกน้ำดังโครม:** ปลาก็จะตื่นตกใจหนีไปก่อนที่จะทันได้มองเห็นเหยื่อ
* **การแคสติ้งที่สมบูรณ์แบบ:** คือการส่งเหยื่อลงสู่จุดตายอย่างแม่นยำ ไร้เสียงรบกวน และพร้อมสร้างแอ็กชันได้ทันทีในวินาทีแรก

## 7. สรุป 5 บัญญัติทองคำสำหรับการแคสติ้งสปินนิ่ง

| บทเรียนหลัก | รายละเอียดทางเทคนิค | เหตุผลและจุดประสงค์ |
|---|---|---|
| **1. การจับรอก (Two-Finger)** | ประกบขารอกด้วยนิ้วกลางและนิ้วนาง | มั่นคง ข้อมือไม่เกร็ง และป้องกันไม่ให้นิ้วไปชน Line Roller ทำลายสาย |
| **2. การเกี่ยวสาย (Line Pickup)** | หมุน Line Roller ขึ้นบนสุด แล้วใช้นิ้วชี้เกี่ยว | ทำงานรวดเร็ว ไม่ต้องละสายตา ไม่ต้องใช้มือซ้ายเอื้อมควานหาสาย |
| **3. ระบบเบรก (Feathering)** | ใช้นิ้วชี้แตะขอบสปูลเบาๆ ควบคุมสายตลอดการบิน | ป้องกันสายพอง ชะลอเหยื่อให้ลงตรงเป้า และหยุดสายทันทีที่เหยื่อแตะน้ำ |
| **4. ระนาบการตี (Overhead)** | ถือตรง ยกตรง ตีตรง ในระนาบ 12 นาฬิกา | เหยื่อไม่แกว่งข้ามศีรษะ วิถีเหยื่อพุ่งตรงเป็นเส้นเดียวกับแนวเล็ง |
| **5. วิถีต่ำและการสกิป (Skipping)** | มองเป้าหมายปลายทาง ไม่มองผิวน้ำข้างหน้า | ปรับมุมเหยื่อให้ขนานน้ำและใช้ Feathering เชิดหัวเหยื่อให้กระดอนลอดสิ่งกีดขวาง |

มุราตะทิ้งท้ายว่า สรีระการจับและการควบคุมสายด้วยนิ้วชี้ อาจต้องใช้เวลาฝึกฝนให้เข้ามือเพียงไม่กี่วัน แต่ผลลัพธ์ที่จะอยู่กับคุณตลอดไปคือ **ความมั่นใจ ความแม่นยำ และความสุขในการตกปลาที่เหนือกว่าเดิมในทุกครั้งที่สะบัดคัน**

## 8. ตารางคำศัพท์เทคนิคภาษาญี่ปุ่นในคลิป (Glossary)

| คำศัพท์ภาษาญี่ปุ่น | คำอ่าน (Romaji) | ความหมายในภาษาไทย |
|---|---|---|
| **ツーフィンガーグリップ** | Two-Finger Grip | การจับกริปรอกสปินนิ่งโดยประกบขารอกระหว่างนิ้วกลางและนิ้วนาง |
| **フェザリング** | Feathering | การใช้นิ้วชี้แตะขอบสปูลเบาๆ เพื่อควบคุมความเร็วสายและหยุดเหยื่อ |
| **ベール** | Bail (Bail Arm) | ก้านหน้ารอก ทำหน้าที่เปิด-ปิดเพื่อปล่อยและเก็บสาย |
| **ラインローラー** | Line Roller | ลูกกลิ้งเก็บสายบนก้านหน้ารอก จุดที่ต้องระวังไม่ให้นิ้วไปสัมผัสโดน |
| **スプール** | Spool | หลอดเก็บสายของรอกสปินนิ่ง |
| **オーバーヘッドキャスト** | Overhead Cast | การตีเหยื่อข้ามศีรษะในแนวดิ่ง ให้ความแม่นยำและวิถีตรงที่สุด |
| **サイドキャスト** | Side Cast | การตีเหยื่อในแนวนอนเพื่อลอดสิ่งกีดขวางด้านบน |
| **バックハンドキャスト** | Backhand Cast | การตวัดคันหลังมือข้ามลำตัวเพื่อตีเข้ามุมอับ |
| **フリップキャスト** | Flip Cast | การสะบัดปลายคันสั้นๆ เพื่อส่งเหยื่อระยะประชิดอย่างเงียบเชียบ |
| **スキッピング** | Skipping | เทคนิคการตีเหยื่อให้กระดอนผิวน้ำเข้าไปใต้สิ่งกีดขวาง |

## 9. เช็กลิสต์ฝึกซ้อมแคสติ้งสปินนิ่ง (Spinning Practice Checklist)

- [ ] **เช็กนิ้วจับรอก:** ขารอกอยู่ระหว่างนิ้วกลางและนิ้วนางหรือไม่ (Two-Finger Grip)

- [ ] **เช็กการเกี่ยวสาย:** สายพาดอยู่ที่ข้อแรกของปลายนิ้วชี้อย่างนุ่มนวล

- [ ] **เช็ก Feathering:** เหยียดนิ้วชี้ไปแตะขอบสปูล ชะลอเหยื่อ และล็อคสายทันทีที่เหยื่อตกถึงผิวน้ำ
