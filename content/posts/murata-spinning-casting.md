ภายในศูนย์ทดสอบอุปกรณ์ในร่มของค่ายเหยื่อปลอม DUO สระน้ำใสทอดยาวเป็นแนวตรงสำหรับทดสอบแอ็กชันเหยื่อและการเหวี่ยงสาย **มุราตะ โมโตอิ (村田基 - Hajime Murata)** หรือ "จิม" ตำนานแห่งวงการตกปลาญี่ปุ่น ยืนสงบนิ่งริมสระพร้อมคันสปินนิ่งโทนสีแดงดำในมือ ก่อนที่เขาจะเอ่ยประโยคเปิดคลิปที่ทำลายความเชื่อดั้งเดิมของนักตกปลาแทบทุกคน:

> **"จริงๆ แล้ว การตกปลาด้วยรอกสปินนิ่ง (Spinning) มีความยากและละเอียดอ่อนกว่ารอกเบทคาสติ้ง (Baitcasting) เสียอีก"**

สำหรับคนทั่วไป รอกสปินนิ่งมักถูกแปะป้ายว่าเป็น "รอกสำหรับผู้เริ่มต้น" เพราะไม่มีระบบหน่วงให้ต้องปรับแต่ง ไม่ต้องกลัวสายฟู่รุนแรงเหมือนรอกเบท แค่เหวี่ยงคันออกไป ใครๆ ก็ส่งเหยื่อให้ลอยไปข้างหน้าได้ แต่มุราตะชี้ให้เห็นว่า หากเป้าหมายของคุณคือการส่งเหยื่อเข้าไปตกในช่องแคบใต้กิ่งไม้ หรือวางเหยื่อลงจุดตายเดิมซ้ำๆ ในระยะ 20-30 เมตร โดยที่เหยื่อตกกระทบน้ำอย่างแผ่วเบา รอกสปินนิ่งกลับต้องการความแม่นยำจากปลายนิ้วมากกว่ารอกเบทหลายเท่าตัว

คลิปนี้คือบทเรียนการรื้อฟื้นและจัดระเบียบเบสิกใหม่ทั้งหมด ตั้งแต่การประกบขารอกด้วยกริปสองนิ้ว กฎเหล็ก 1-2-3 ในการเปิดหน้ารอกโดยไม่ต้องละมือไปควานหาสาย ไปจนถึงการปลดปล่อยพลังงานจากแบลงก์คันเบ็ดที่จะเปลี่ยนการตีสปินนิ่งของคุณไปตลอดกาล

![มุราตะ โมโตอิ ในคลาส spinning cast ที่โรงทดสอบของ DUO](assets/murata-spin-opening.jpg)

**ภาพที่ 1:** มุราตะ โมโตอิ ในคลาสสอนแคสติ้งสปินนิ่ง ณ ศูนย์ทดสอบ DUO ถ่ายทอดความรู้เบื้องหลังการควบคุมสายที่ถูกต้อง

## 1. รื้อภาพจำ: ทำไมสปินนิ่งถึงต้องการความละเอียดสูงกว่าเบท?

ความเข้าใจผิดอันดับหนึ่งที่พบได้บ่อย คือการคิดว่ารอกสปินนิ่งเล่นง่ายและไม่มีทางสายฟู่ แต่ในความเป็นจริง รอกสปินนิ่งไม่มีระบบหน่วงแม่เหล็กหรือหน่วงเม็ดราคอยชะลอสปูลเหมือนรอกเบทคาสติ้ง เมื่อเปิดหน้ารอก (Bail Arm) สายเอ็นหรือสาย PE จะคลายตัวหลุดออกจากขอบสปูลเป็นวงกว้างตามแรงเฉื่อยของเหยื่ออย่างอิสระ

นั่นหมายความว่า **"ปลายนิ้วชี้ของนักตกปลาเพียงนิ้วเดียว คือระบบเบรกทั้งระบบของรอกสปินนิ่ง"** 

หากตำแหน่งการจับรอกคลาดเคลื่อนเพียงไม่กี่มิลลิเมตร นิ้วชี้จะไม่สามารถเอื้อมไปแตะขอบสปูลเพื่อชะลอสายได้ทันเวลา ผลที่ตามมาคือเหยื่อจะพุ่งทะลุเลยหมาย สายหน้าจะหย่อนยานจนเกิดขดสายพันกันเป็นปม (Wind Knot หรือ อาการหูหนวดกุ้ง) และทำให้เสียสายไปเปล่าๆ ในการตีไม้ถัดไป การฝึกสปินนิ่งจึงต้องเริ่มต้นจากตำแหน่งของนิ้วมือเป็นอันดับแรก

## 2. สองนิ้วเท่านั้น (Two-Finger Grip): ปกป้องสายและเปิดอิสระให้นิ้วชี้

จุดแรกที่มุราตะลงมือสาธิตและปรับแก้ให้เห็นจะๆ คือ **ตำแหน่งการประกบขารอก (Reel Foot)** ซึ่งเขาเน้นย้ำว่าต้องใช้ **กริปสองนิ้ว (Two-Finger Grip)** เท่านั้น นั่นคือการวางขารอกไว้กึ่งกลางระหว่าง **นิ้วกลางและนิ้วนาง**

```
[ จับสองนิ้ว : Two-Finger ]  --> นิ้วกลาง + นิ้วนางประกบขารอก (ระยะห่างจาก Line Roller พอดีเป๊ะ)
[ จับสามนิ้ว : Three-Finger ] --> นิ้วชี้ + กลาง + นางอยู่หน้าขารอก (นิ้วเบียดชน Line Roller สายพัง!)
[ จับนิ้วเดียว : One-Finger ]   --> ท่าการ์ล (Garl) อุ้งมือหลวม ข้อมือไร้แรงส่ง คุมคันไม่ได้
```

### อันตรายของการจับสามนิ้ว (Three-Finger Grip)
หลายคนชอบเอานิ้วชี้ นิ้วกลาง และนิ้วนาง ไปรวมกันอยู่ด้านหน้าขารอก (เหลือเพียงนิ้วก้อยนิ้วเดียวอยู่ข้างหลัง) เพราะคิดว่าจับได้กระชับมือดี แต่มุราตะสาธิตให้เห็นว่า เมื่อจับในลักษณะนี้ อุ้งมือจะถูกดันขึ้นไปชิดกับตัวเรือนรอกมากเกินไป 

ในจังหวะที่หมุนรอกเก็บสาย ก้านโรเตอร์จะหมุนพัดเอา **ลูกกลิ้งเก็บสาย (Line Roller)** วิ่งมาเฉียดชนกับหลังข้อนิ้วมืออยู่ตลอดเวลา เกิดเป็นเสียงเสียดสี "กึกๆ ขูดๆ" สิ่งสกปรกและแรงกดจากนิ้วจะไปบดขยี้สายเอ็นเข้ากับขอบโลหะของลูกกลิ้ง ทำลายสารเคลือบสาย ทำให้สายเกิดรอยพับ รอยขูดขีด และเปื่อยขาดได้ง่ายเมื่อต้องสู้กับปลาใหญ่

### ข้อเสียของการจับนิ้วเดียว (ท่าการ์ล - Garl Grip)
ในทางกลับกัน การจับโดยวางนิ้วชี้ไว้ข้างหน้าขารอกเพียงนิ้วเดียว จะทำให้จุดศูนย์ถ่วงของรอกหลุดออกไปนอกฝ่ามือ ส่งผลให้ข้อมือขาดแรงค้ำยัน คันเบ็ดจะส่ายเซไปมา และนิ้วชี้จะต้องเอื้อมเหยียดสุดตัวเพื่อไปควานหาสาย ทำให้การควบคุมสายขาดความมั่นคง

### กริปสองนิ้ว: จุดสมดุลตามสรีรศาสตร์
การประกบขารอกด้วยนิ้วกลางและนิ้วนาง จะทิ้งระยะห่างระหว่างอุ้งมือกับ Line Roller ไว้อย่างปลอดภัย ไม่มีการเสียดสีหรือชนนิ้วแม้แต่มิลลิเมตรเดียว ทั้งยังช่วยถ่ายเทน้ำหนักรอกเข้าสู่แกนกลางฝ่ามือ ทำให้ข้อมือมีพลังพยุงคันอย่างสมบูรณ์ และเหลือนิ้วชี้ไว้สำหรับเกี่ยวสายและเบรกสายได้อย่างอิสระที่สุด

![การจับรอก spinning ด้วยสองนิ้ว](assets/murata-spin-two-finger.jpg)

**ภาพที่ 2:** การจับรอกสปินนิ่งด้วยกริปสองนิ้ว (นิ้วกลางและนิ้วนางประกบขารอก) ช่วยรักษาระยะห่างจาก Line Roller ได้อย่างปลอดภัย

## 3. กฎเหล็ก 1-2-3: ระบบเกี่ยวสายและเปิดหน้ารอกโดยไม่ต้องควาน

ข้อผิดพลาดที่พบเห็นได้บ่อยที่สุดในสนาม คือการที่นักตกปลาตีเหยื่อลงน้ำแล้ว พอจะตีครั้งต่อไป กลับใช้มือซ้ายเอื้อมไปควานดึงสายเอ็นออกจากหน้ารอกเพื่อนำมาพาดเข้าสู่นิ้วชี้ มุราตะเตือนว่าการกระทำเช่นนั้นคือต้นตอของหายนะสายฟู่ที่ทำให้นักตกปลาต้องตัดสายทิ้งเป็นสิบๆ เมตร

มุราตะจึงได้กำหนดขั้นตอนมาตรฐานที่เรียกว่า **"จังหวะ 1-2-3 (หมุน - เกี่ยว - เปิด)"** เพื่อสร้างความต่อเนื่องและป้องกันสายหย่อน:

```
[ STEP 1 : หมุน ]  --> หมุนด้ามรอกให้ Line Roller เลื่อนขึ้นมาอยู่ตำแหน่งบนสุด
[ STEP 2 : เกี่ยว ]  --> ยื่นนิ้วชี้ขวาไปเกี่ยวสายหน้า Line Roller ให้ตึงพาดข้อนิ้ว
[ STEP 3 : เปิด ]  --> มือซ้ายพลิกเปิดหน้ารอก (Bail Arm) ขึ้นอย่างนุ่มนวล
```

### ทำไมการควานหาสายด้านข้างถึงทำให้เกิดสายฟู่?
เมื่อคุณใช้มือซ้ายดึงสายจากด้านข้าง แรงดึงจะทำให้ขดสายบนสปูลสูญเสียความตึงเครียด (Line Tension) ขดสายที่หลวมจะคลายตัวกระโดดข้ามขอบสปูลไปกองอยู่ด้านหลัง หรือเกิดเป็นห่วงสายยื่นออกมาที่เรียกว่า **"หนวดกุ้ง" (Loop / ピョン吉)** 

เมื่อคุณหวดคันในไม้ถัดไป ห่วงสายที่หลวมนี้จะถูกสายท่อนหลังกระชากหลุดออกมาพร้อมกันหลายสิบรอบ กลายเป็นปมสายพันกันยุ่งเหยิงกลางอากาศ มุราตะระบุว่าความประมาทนี้อาจทำให้นักตกปลา **สูญเสียสายดีๆ ไปถึง 20-30 เมตรในพริบตาเดียว**

การใช้สูตร 1-2-3 จะทำให้สายเอ็นถูกล็อคอยู่บนปลายนิ้วชี้ในแนวระนาบที่ตรงเป๊ะตลอดเวลา สายจะไม่หย่อนตัว ไม่เกิดห่วงหนวดกุ้ง และพร้อมสำหรับการตีเหยื่อครั้งต่อไปได้ในเสี้ยววินาที

**ภาพที่ 4:** การหมุนรอกเพื่อนำ Line Roller ขึ้นมาด้านบนสุด ก่อนใช้นิ้วชี้เกี่ยวสายและเปิดหน้ารอกตามจังหวะ 1-2-3

## 4. ศาสตร์การแคสต์: โยนคันไปข้างหลังแล้วหยุด เพื่อสะสมแรงสปริง

เมื่อสายหน้าถูกจัดระเบียบเข้าสู่นิ้วชี้เรียบร้อยแล้ว ขั้นตอนต่อไปคือการส่งเหยื่อออกไปสู่เป้าหมาย ซึ่งมุราตะเน้นย้ำหลักฟิสิกส์สำคัญว่า: **"การตีเหยื่อไม่ใช่การงัดหรือยกคันขึ้นฟ้า แต่คือการโยนคันไปด้านหลังแล้วหยุดมือเพื่อให้คันโก่งตัว"**

```
   (1) โยนคันไปด้านหลัง         (2) หยุดมือกระทันหัน (1-2 นาฬิกา)         (3) คันสะบัดดีดเหยื่อพุ่งตรง
        [ Take-back ]                    [ Abrupt Stop ]                       [ Forward Flex ]
             \                                 |                                      ----->
              \                                v                                  (Line Target)
```

### จังหวะการโหลดคัน (Rod Loading)
1. **Take-back:** ใช้ข้อมือโยนปลายคันไปด้านหลังอย่างนุ่มนวล
2. **Abrupt Stop:** หยุดการเคลื่อนไหวของมือทันทีเมื่อคันทำมุมประมาณ 1-2 นาฬิกาด้านหลัง มวลน้ำหนักและแรงเฉื่อยของเหยื่อจะดึงปลายคันเบ็ดให้โค้งงออย่างเต็มที่ สะสมพลังงานสปริงตัว (Rod Loading)
3. **Release:** สะบัดข้อมือกลับมาข้างหน้า ปล่อยให้น้ำหนักสปริงของแบลงก์คาร์บอนดีดเหยื่อพุ่งแหวกอากาศออกไปเอง โดยนักตกปลาไม่ต้องออกแรงกระชากกล้ามแขนเลยแม้แต่น้อย

### ความจริงเรื่องขนาดสาย: ไม่จำเป็นต้องใช้สายบางเสมอไป
ในระหว่างการสาธิต มุราตะใช้ **เหยื่อแครงค์เบทขนาดเล็กน้ำหนักเพียง 3.5 กรัม ร่วมกับสายเอ็นขนาดใหญ่ถึง 8 ปอนด์** แต่สามารถดีดเหยื่อพุ่งเป็นเส้นตรงแหวกอากาศไปแตะระยะ **20 กว่าเมตร** ได้อย่างง่ายดาย

มุราตะอธิบายเพื่อทำลายค่านิยมผิดๆ ว่า นักตกปลาจำนวนมากเข้าใจว่าถ้าเหยื่อเบาจะต้องลดขนาดสายให้บางลงเรื่อยๆ (เช่น ลดเหลือ 2-3 ปอนด์) แต่ในความเป็นจริง หากคันเบ็ดมีแอ็กชันที่เหมาะสม และนักตกปลามีจังหวะการสะสมแรงดีดของคันที่ถูกต้อง เหยื่อหนัก 3-5 กรัมก็สามารถตีร่วมกับสาย 8-10 ปอนด์ได้ระยะทางที่ยอดเยี่ยม โดยไม่ต้องเสี่ยงกับปัญหาสายขาดง่ายเมื่อปลาใหญ่เข้าชาร์จ

## 5. เบรกด้วยปลายนิ้ว (Feathering): เสกเหยื่อให้ลงนิ่มระดับเซนติเมตร

หลังจากปล่อยนิ้วชี้ให้สายพุ่งออกไปแล้ว สิ่งที่ต้องทำทันทีคือการควบคุมวิถีของเหยื่อด้วยเทคนิค **Feathering (การใช้นิ้วชี้เป็นระบบเบรก)**

```
[ สัมผัสแผ่วเบา ]  --> นิ้วชี้จ่อขอบสปูล ปล่อยให้ขดสายกระทบผิวนิ้วเพื่อคุมความเร็ว
[ หยุดกึกสั่งได้ ]   --> ทันทีที่เหยื่อแตะจุดหมาย กดนิ้วชี้ทาบขอบสปูลเพื่อหยุดสายทันที
```

### ประโยชน์ 3 ประการของการใช้นิ้วชี้เบรกสปูล
1. **คุมระยะตกไม่ให้เลยเป้า:** ป้องกันไม่ให้เหยื่อพุ่งทะลุเลยแนวตลิ่งหรือเข้าไปติดกิ่งไม้ฝั่งตรงข้าม
2. **เหยื่อตกน้ำอย่างไร้เสียง (Soft Touchdown):** การแตะเบรกชะลอสายก่อนเหยื่อกระทบน้ำ จะช่วยพยุงหัวเหยื่อให้ร่อนลงสู่ผิวน้ำอย่างนิ่มนวล ไม่ส่งเสียงดังตูมจนปลาตกใจตื่นหนี
3. **สายตึงพร้อมสร้างแอ็กชันทันที:** การล็อคสายทันทีที่เหยื่อตกถึงน้ำ จะตัดปัญหาอาการสายหย่อนปลิวตามลม ทำให้เหยื่อพร้อมทำงานตั้งแต่รอบแรกที่หมุนรอก

![การใช้นิ้วแตะสปูลเพื่อเบรกสาย](assets/murata-spin-brake.jpg)

**ภาพที่ 6:** การยื่นปลายนิ้วชี้ไปประคองสัมผัสขอบสปูลเพื่อชะลอสายและล็อคสายอย่างแม่นยำ

## 6. ท่าแคสต์ทางเลือกสำหรับหมายอุปสรรคสูง

เมื่อทำความเข้าใจการโหลดคันและการเบรกสายในท่า Overhead ได้อย่างเชี่ยวชาญแล้ว มุราตะได้ขยายขอบเขตการแคสต์ไปสู่ท่าทางเลือกอื่นๆ ที่จำเป็นสำหรับการเอาชีวิตรอดในหมายธรรมชาติ:

* **Side Cast (การตีด้านข้าง):** ลดระนาบการเหวี่ยงลงมาขนานกับผิวน้ำ ใช้เมื่อมีเพดานสะพาน กิ่งไม้ หรือสิ่งปลูกสร้างขวางอยู่เหนือศีรษะ
* **Backhand Cast (การตวัดคันหลังมือ):** ตวัดคันข้ามหน้าอกเพื่อส่งเหยื่อเข้าสู่เป้าหมายทางฝั่งตรงข้ามของลำตัว ช่วยให้นักตกปลาสามารถยิงเหยื่อเข้าซอกแคบได้โดยไม่ต้องขยับตัวหรือเปลี่ยนทิศทางการยืน
* **Low Trajectory Overhead (การตีวิถีต่ำ):** การตี Overhead โดยกดมุมปล่อยเหยื่อให้พุ่งขนานเรี่ยผิวน้ำ โดยที่เหยื่อไม่เคยลอยสูงเกินระดับสายตา ช่วยทะลวงลมต้านและส่งเหยื่อมุดเข้าไปใต้โครงสร้างเตี้ยๆ ได้อย่างยอดเยี่ยม

![การตี side cast ในโรงทดสอบ](assets/murata-spin-side.jpg)

**ภาพที่ 7:** การตี Side Cast ในโรงทดสอบเพื่อส่งเหยื่อในแนวนอนเลาะขนานไปกับแนวสิ่งกีดขวาง

![การตี backhand ในโรงทดสอบ](assets/murata-spin-backhand.jpg)

**ภาพที่ 8:** การตี Backhand Cast ช่วยให้นักตกปลาสามารถส่งเหยื่อเข้าสู่มุมอับข้ามลำตัวได้อย่างคล่องตัว

## 7. บทสรุป: สปินนิ่งไม่ใช่เรื่องยาก ถ้าเข้าใจ 3 เสาหลัก

มุราตะ โมโตอิ สรุปหัวใจสำคัญของคลาสแคสติ้งสปินนิ่งตลอดทั้งคลิปไว้เป็น **3 เสาหลักที่ต้องจำให้ขึ้นใจ**:

1. **Two-Finger Grip:** วางขารอกไว้ระหว่างนิ้วกลางและนิ้วนางเสมอ เพื่อความมั่นคงและป้องกันการขูดทำลายสายของ Line Roller
2. **The 1-2-3 Routine:** หมุนโรลเลอร์ขึ้นบนสุด -> ใช้นิ้วชี้เกี่ยวสาย -> เปิดหน้ารอก ป้องกันปัญหาสายหย่อนและหนวดกุ้งได้อย่างเด็ดขาด
3. **Rod Flex & Feathering:** โยนคันไปด้านหลังแล้วหยุดเพื่อให้คันสะสมแรงดีด และใช้นิ้วชี้ทำหน้าที่เป็นระบบเบรกชะลอเหยื่อให้ลงตรงเป้าหมาย

เมื่อจัดระเบียบสรีระและจังหวะของมือได้ถูกต้อง การตีรอกสปินนิ่งจะกลายเป็นศิลปะที่สร้างความเพลิดเพลิน ความแม่นยำ และประสิทธิภาพในการตกปลาที่เหนือชั้นอย่างแท้จริง

![มุราตะ โมโตอิ ปิดท้ายคลาส spinning cast](assets/murata-spin-closing.jpg)

**ภาพที่ 9:** มุราตะ โมโตอิ ปิดท้ายคลาสสอนแคสติ้งสปินนิ่ง ย้ำเตือนให้นักตกปลาหมั่นฝึกฝนพื้นฐานให้กลายเป็นสัญชาตญาณ

## 8. การนำไปปรับใช้กับเกมตกปลาในไทย

หลักสูตรสปินนิ่งของมุราตะสามารถนำมาประยุกต์ใช้กับแหล่งน้ำและปลาล่าเหยื่อในบ้านเราได้อย่างหลากหลาย:

* **เกมตกปลาช่อนและปลากระสูบน้ำจืด:** การใช้ **Two-Finger Grip** ร่วมกับ **Feathering** ช่วยให้ส่งเหยื่อผิวน้ำหรือสปูนขนาดเล็กเข้าไปชิดตลิ่งและแนวกอหญ้าได้อย่างเงียบกริบ ปลาไม่ตื่น
* **เกมตกปลากะพงบ่อและกะพงวัง:** จังหวะ **1-2-3** ช่วยขจัดปัญหาสาย PE ตีเกลียวหรือพองเป็นห่วงเมื่อต้องตีเหยื่อน้ำหนักเบาอย่างไมโครปลั๊กหรือหนอนยางต่อเนื่องหลายร้อยไม้ต่อวัน
* **เกมสตรีมตกปลาพลวงและกระสูบน้ำตก:** การใช้ **Low Trajectory Overhead** ช่วยให้ตีทะลุร่มไม้หนาทึบและส่งเหยื่อลงสู่แอ่งน้ำวนหลังก้อนหินได้อย่างแม่นยำ

## 9. ตารางคำศัพท์เทคนิคภาษาญี่ปุ่นในคลิป (Glossary)

| คำศัพท์ภาษาญี่ปุ่น | คำอ่าน (Romaji) | ความหมายในภาษาไทย |
|---|---|---|
| **スピニング** | Spinning | รอกสปินนิ่งและระบบชุดอุปกรณ์สปินนิ่ง |
| **キャスティング** | Casting | ศาสตร์และทักษะการเหวี่ยงตีเหยื่อปลอม |
| **ツーフィンガーグリップ** | Two-Finger Grip | กริปการจับรอกโดยใช้นิ้วกลางและนิ้วนางประกบขารอก |
| **フェザリング / サミング** | Feathering / Thumbing | การใช้นิ้วชี้แตะขอบสปูลเบาๆ เพื่อควบคุมความเร็วสายและหยุดเหยื่อ |
| **ベール** | Bail (Bail Arm) | ก้านเปิด-ปิดหน้ารอกสำหรับจ่ายและเก็บสาย |
| **ラインローラー** | Line Roller | ลูกกลิ้งเก็บสายบนก้านหน้ารอก จุดที่ต้องระวังไม่ให้นิ้วชน |
| **タラシ** | Tarashi | ระยะความยาวของสายหน้าห้อยเหยื่อจากปลายคันเบ็ด |
| **ロッドの反発力** | Rod no Hanpatsuryoku | พลังงานแรงดีดสะท้อนกลับตัวของแบลงก์คันเบ็ด |
| **ピョン吉 (ひょんきち)** | Pyonkichi / Loop | อาการขดสายหลวมยื่นออกมานอกสปูลเป็นหนวดกุ้ง สาเหตุหลักของสายฟู่ |

## 10. เช็กลิสต์ฝึกซ้อมสปินนิ่ง 1-2-3 (Spinning Checklist)

- [ ] **เช็กการจับรอก:** นิ้วกลางและนิ้วนางประกบขารอก (Two-Finger Grip) อย่างมั่นคง
- [ ] **เช็กสเต็ป 1:** หมุนด้ามรอกให้ Line Roller เลื่อนขึ้นมาอยู่ตำแหน่งบนสุดก่อนเสมอ
- [ ] **เช็กสเต็ป 2:** ใช้นิ้วชี้ขวาเกี่ยวสายตรงหน้า Line Roller โดยไม่ต้องใช้มือซ้ายควานหา
- [ ] **เช็กสเต็ป 3:** ใช้มือซ้ายพลิกเปิดหน้ารอกขึ้น สายหน้าตึงพาดข้อนิ้วชี้
- [ ] **เช็กจังหวะ Take-back:** โยนคันไปด้านหลังแล้ว "หยุดมือ" ที่ 1-2 นาฬิกาเพื่อโหลดแรงดีดของคัน
- [ ] **เช็ก Feathering:** ยื่นนิ้วชี้ไปรอชะลอสายที่ขอบสปูล และกดล็อคสายทันทีที่เหยื่อแตะผิวน้ำ
